# AWS Updates - 2026-01-27

## AWS What's New

### AWS Deadline Cloud now supports editing job name and description

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/01/aws-deadline-cloud-editing-job-name-description/
- **Published**: 2026-01-27

<p>AWS Deadline Cloud now supports editing job names and descriptions after submission. This new feature makes it easier to organize and identify jobs after submission by updating names or adding useful tracking details in the description field.<br /> <br /> Job names and descriptions are critical metadata for organizing and understanding between users and projects, often tracking things like shot and sequence number across systems. Previously they could only be set at job creation during submission, being able to edit them after submission allows you to fix issues in naming as well as add key tracking information to the job description for other users.<br /> <br /> You can edit job names and descriptions using the AWS SDK, Deadline client, and Deadline Monitor. To learn more see the&nbsp;<a href="https://docs.aws.amazon.com/deadline-cloud/latest/userguide/jobs-monitoring.html">AWS Deadline Cloud documentation</a>.</p>
