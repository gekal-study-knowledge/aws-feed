# AWS Updates - 2026-02-25

## AWS What's New

### AWS Security Agent adds support for penetration tests on shared VPCs across AWS accounts

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/02/aws-security-agent-adds-penetration-tests-shared/
- **Published**: 2026-02-25

<p>AWS Security Agent now enables customers to run penetration tests against Virtual Private Cloud (VPC) resources shared from other AWS accounts within the same organization. This&nbsp;<a href="https://docs.aws.amazon.com/securityagent/latest/userguide/connect-agent-vpc.html">new capabilit</a>y allows security teams to perform comprehensive security assessments across their multi-account environments using AWS Security Agent. By leveraging AWS Resource Access Manager (RAM), customers can securely share VPC resources from sub-accounts to a central AWS account where penetration testing is conducted.<br /> <br /> This feature addresses the challenge of testing distributed architectures spanning multiple AWS accounts. Security professionals can now create an Agent Space in a central account and use RAM to access VPC resources from connected sub-accounts for testing. This streamlines security assessments for organizations with complex multi-account setups. The ability to comprehensively test shared VPC resources enhances an organization's overall security posture.<br /> <br /> To get started, ensure your accounts are part of the same AWS Organization and configure resource sharing using RAM. Then launch AWS Security Agent in your central account to begin penetration testing across the shared VPC resources. For more information on AWS Security Agent and its penetration testing capabilities, visit the&nbsp;<a href="https://docs.aws.amazon.com/securityagent/latest/userguide/what-is.html">AWS Security Agent documentation</a>.&nbsp;</p>
