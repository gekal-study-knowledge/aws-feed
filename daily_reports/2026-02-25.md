# AWS Updates - 2026-02-25

## AWS What's New

### AWS launches a playground for interactive Aurora DSQL database exploration

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/02/amazon-aurora-dsql-launches-playground/
- **Published**: 2026-02-25

<p>Today, AWS announces a browser-based playground that enables developers to interact with an Amazon Aurora DSQL database without requiring an AWS account. With zero setup or infrastructure configuration, developers can create schemas, load data, and execute SQL queries directly form their browser.<br /> <br /> The playground for Aurora DSQL provides an instant, ephemeral database environment, making it easy to experiment and learn. Built-in sample datasets help developers quickly explore core Aurora DSQL capabilities and get hands-on experience in minutes.<br /> <br /> To start exploring, visit the <a href="https://playground.dsql.demo.aws/">playground</a> for Aurora DSQL. To get started with your production workloads and learn more visit <a href="https://aws.amazon.com/rds/aurora/dsql/">Amazon Aurora DSQL</a>.</p>
