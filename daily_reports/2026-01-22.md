# AWS Updates - 2026-01-22

## AWS What's New

### AWS expands Resource Control Policies support for Cognito and CloudWatch Logs

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/01/aws-expands-resource-control-policies
- **Published**: 2026-01-22

<p>AWS Resource Control Policies (RCPs) now provide support for <a href="https://aws.amazon.com/pm/cognito/?trk=de90528c-2450-48d7-9981-bc556d44c9ab&amp;sc_channel=ps&amp;trk=de90528c-2450-48d7-9981-bc556d44c9ab&amp;sc_channel=ps&amp;ef_id=EAIaIQobChMI1oPdpd-JkgMVEh-tBh0iWzpHEAAYASAAEgLl7_D_BwE:G:s&amp;s_kwcid=AL!4422!3!652240143559!e!!g!!cognito!19878797452!155825919588&amp;gad_campaignid=19878797452&amp;gbraid=0AAAAADjHtp-6asfTXR8BCPoEoERBRak--&amp;gclid=EAIaIQobChMI1oPdpd-JkgMVEh-tBh0iWzpHEAAYASAAEgLl7_D_BwE" target="_blank">Amazon Cognito</a> and <a href="https://aws.amazon.com/cloudwatch/?refid=de90528c-2450-48d7-9981-bc556d44c9ab" target="_blank">Amazon CloudWatch Logs</a>. Resource<u> </u>control policies (RCPs) are a type of organization policy that you can use to manage permissions in your organization. RCPs offer central control over the maximum available permissions for resources in your organization.<br /> <br /> With this expansion, you can now use RCPs to manage permissions for Amazon Cognito and Amazon CloudWatch Logs resources. For example, you can create policies that prevent identities outside your organization from accessing these resources, helping you build a <a href="https://aws.amazon.com/identity/data-perimeters-on-aws/" target="_blank">data perimeter</a> and enforce baseline security standards across your AWS environment.<br /> <br /> RCPs are available in all AWS commercial Regions and AWS GovCloud (US) Regions. To learn more about RCPs and view the full list of supported AWS services, visit the <a href="https://docs.aws.amazon.com/organizations/latest/userguide/orgs_manage_policies_rcps.html" target="_blank">Resource control policies (RCPs) documentation</a> in the AWS Organizations User Guide.</p>
