# AWS Updates - 2026-03-19

## AWS What's New

### Amazon EC2 Fleet now supports interruptible Capacity Reservations

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/03/amazon-ec2-fleet-interruptible-capacity-reservations/
- **Published**: 2026-03-19

<p>Amazon EC2 Fleet now supports interruptible Capacity Reservations. EC2 Fleet allows you to launch instances across multiple instance types and Availability Zones. Starting today, you can specify interruptible Capacity Reservation IDs across your Launch Templates to provision instances in a single EC2 Fleet call.</p> 
<p>When On-Demand Capacity Reservations are not in use, customers can make them temporarily available as interruptible reservations within their AWS Organization to improve utilization and save costs. When these interruptible reservations are available to your account, you can now use EC2 Fleet to easily consume them.</p> 
<p>This feature is available in all AWS commercial regions. To get started, refer to the&nbsp;<a href="https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/ec2-fleet-launch-instances-interruptible-cr-walkthrough.html">EC2 Fleet documentation</a>. To learn more about interruptible Capacity Reservations, visit the <a href="https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/interruptible-capacity-reservations.html">EC2 Capacity Reservations user guide</a>.&nbsp;<br /> </p>
