## AWS What's New

### Announcing Amazon DocumentDB long-term support (LTS) on 5.0

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/02/announcing-amazon-documentdb-5-0-long-term-support
- **Published**: 2026-02-16

<p>Starting today, Amazon DocumentDB (with MongoDB compatibility) offers Long-Term Support (LTS) on DocumentDB 5.0, enabling customers to reduce database upgrade frequency and maintenance overhead. LTS versions will receive only critical stability and security patches without introducing new features.<br /> <br /> To get started, create a new DocumentDB cluster engine version 5.0.0, or patch your existing engine version 5.0.0 cluster during your next maintenance window. Verify you're running the required Engine Patch Version by connecting to your cluster and running&nbsp;db.runCommand({getEngineVersion: 1})<b>.</b>&nbsp;Ensure you're running Engine Patch Version 3.0.17983 or later.<br /> <br /> This LTS release is available in all Amazon Web Services regions where DocumentDB is offered.&nbsp;For more details about DocumentDB LTS, and how to check to see what engine patch version you’re on, refer to the <a href="https://docs.aws.amazon.com/documentdb/latest/developerguide/docdb-lts-release.html" target="_blank">Long-Term Support (LTS) release for Amazon DocumentDB</a>.</p>
