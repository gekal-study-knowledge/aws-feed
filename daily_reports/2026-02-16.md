# AWS Updates - 2026-02-16

## AWS What's New

### Amazon Aurora now supports Server-Side Encryption by default

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/02/amazon-aurora-server-side-encryption-at-rest
- **Published**: 2026-02-16

<p>Amazon Aurora further strengthens your security posture by automatically applying server-side encryption by default to all new databases clusters, created starting today, using <a href="https://docs.aws.amazon.com/kms/latest/developerguide/concepts.html#aws-owned-key">AWS-owned keys</a>. This encryption is fully managed, transparent to users, with no cost or performance impact.<br /> <br /> Aurora now automatically encrypts all new database clusters created without custom encryption settings using server-side encryption by default. Existing clusters remain unaffected and you can continue using the current encryption configuration with customer-managed or AWS-managed KMS keys.<b> </b>This automatic encryption only applies to new clusters where no encryption configuration is provided. You cannot disable encryption on new clusters, but can choose customer-managed or AWS-managed KMS keys instead of server side encryption during cluster creation. Server side encryption provides encryption protection without requiring you to provision, rotate, or manage keys.<br /> <br /> This update is available in all <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">AWS Regions</a>, including the <a href="https://aws.amazon.com/govcloud-us/">AWS GovCloud (US) Regions</a>. To learn more about encryption at rest, refer to our <a href="https://aws.amazon.com/blogs/database/use-default-encryption-at-rest-for-new-amazon-aurora-clusters/">blog</a> or see <a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/Overview.Encryption.html">Aurora encryption documentation</a>.</p>
