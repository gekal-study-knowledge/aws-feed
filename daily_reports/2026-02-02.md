# AWS Updates - 2026-02-02

## AWS What's New

### Amazon RDS for MySQL now supports new minor versions 8.0.45 and 8.4.8

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/02/amazon-rds-mysql-minor-versions/
- **Published**: 2026-02-02

<p><a href="https://aws.amazon.com/rds/mysql/" target="_blank">Amazon Relational Database Service (Amazon RDS) for MySQL</a> now supports MySQL minor versions 8.0.45 and 8.4.8, the latest minors released by the MySQL community. We recommend upgrading to the newer minor versions to fix known security vulnerabilities in prior versions of MySQL and to benefit from bug fixes, performance improvements, and new functionality added by the MySQL community. Learn more about the enhancements in RDS for MySQL 8.0.45 and 8.4.8 in the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/MySQL.Concepts.VersionMgmt.html" target="_blank">Amazon RDS user guide</a>.<br /> <br /> You can leverage automatic minor version upgrades to automatically upgrade your databases to more recent minor versions during scheduled maintenance windows. You can also use <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/blue-green-deployments.html" target="_blank">Amazon RDS Managed Blue/Green deployments</a> for safer, simpler, and faster updates to your MySQL instances. Learn more about upgrading your database instances, including automatic minor version upgrades and Blue/Green Deployments, in the <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_UpgradeDBInstance.MySQL.html" target="_blank">Amazon RDS User Guide.</a><br /> <br /> Amazon RDS for MySQL makes it simple to set up, operate, and scale MySQL deployments in the cloud. Learn more about pricing details and regional availability at <a href="https://aws.amazon.com/rds/mysql/pricing/" target="_blank">Amazon RDS for MySQL</a>. Create or update a fully managed Amazon RDS for MySQL database in the <a href="https://console.aws.amazon.com/rds/home" target="_blank">Amazon RDS Management Console</a>.</p>
