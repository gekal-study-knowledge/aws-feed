# AWS Updates - 2026-03-03

## AWS Security Bulletins

### MariaDB Server Audit Plugin Comment Handling Bypass

- **Link**: https://aws.amazon.com/security/security-bulletins/rss/2026-006-aws/
- **Published**: 2026-03-03

<p><b>Bulletin ID:</b> 2026-006-AWS<br /> <b>Scope:</b> AWS<br /> <b>Content Type:</b> Informational<br /> <b>Publication Date:</b> 2026/03/03 10:15 AM PST</p> 
<p><b>Description:</b></p> 
<p>Amazon RDS/Aurora is a managed relational database service. We identified CVE-2026-3494. In MariaDB server version through 11.8.5, when server audit plugin is enabled with server_audit_events variable configured with QUERY_DCL, QUERY_DDL, or QUERY_DML filtering, if an authenticated database user invokes a SQL statement prefixed with double-hyphen (‐‐) or hash (#) style comments, the statement is not logged.</p> 
<p><b>Impacted versions:</b></p> 
<p>- MariaDB Server (10.6.24 and prior, 10.11.15 and prior, 11.4.9 and prior, and 11.8.5 and prior)<br /> - Amazon Aurora MySQL (2.12.5 and prior, 3.01.0 to 3.04.5, 3.05.1 to 3.10.2, and 3.11.0)<br /> - Amazon RDS for MySQL (5.7.44-RDS.20251212 and prior, 8.0.11 to 8.0.44, and 8.4.3 to 8.4.7)<br /> - Amazon RDS for MariaDB (10.6.24 and prior, 10.11.4 to 10.11.15, 11.4.3 to 11.4.9, and 11.8.3 to 11.8.5)</p> 
<p><b>Please refer to the article below for the most up-to-date and complete information related to this AWS Security Bulletin.</b></p>
