# AWS Updates - 2026-02-18

## AWS What's New

### Mistral AI Devstral 2 now available on Amazon Bedrock

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/02/mistral-ai-devstral-bedrock/
- **Published**: 2026-02-18

<p>Customers can now use Mistral AI Devstral 2 123B on Amazon Bedrock, a platform for building generative AI applications and agents at production scale.</p> 
<p>Devstral 2 123B is a state-of-the-art, open-weight large language model purpose-built for agentic software engineering workflows. With 123B parameters and deep specialization in code generation, automation, and multi-step reasoning, Devstral 2 is designed for developers building AI-powered engineering agents that can plan, write, and iterate on code at scale. Amazon Bedrock gives customers access to Devstral 2 123B through a single, fully managed API — no infrastructure to provision, no models to host. The model is well-suited for production-grade coding assistants, automated code review pipelines, and complex software development agents requiring long-context comprehension and reliable multi-turn reasoning.</p> 
<p>Devstral 2 123B is now available in Amazon Bedrock across select AWS Regions. For the full list of available AWS Regions, refer to the <a href="https://docs.aws.amazon.com/bedrock/latest/userguide/models-regions.html" target="_blank">documentation</a>.</p> 
<p>To get started with Devstral 2 123B in Amazon Bedrock, visit the <a href="https://aws.amazon.com/bedrock/mistral/" target="_blank">Amazon Bedrock Mistral AI page</a>.</p>
