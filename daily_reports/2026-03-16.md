# AWS Updates - 2026-03-16

## AWS What's New

### Amazon CloudWatch Logs now supports log ingestion using HTTP-based protocol

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/03/cloudwatch-http-log-collector/
- **Published**: 2026-03-16

<p>Amazon CloudWatch Logs now supports HTTP Log Collector (HLC), ND-JSON, Structured JSON and OTEL for&nbsp;sending logs using HTTP-based protocol with bearer token.&nbsp;With this launch, customers can ingest logs where AWS SDK integration is not&nbsp;feasible, such as with third-party or packaged software.&nbsp;The new endpoints are:</p> 
<ul> 
 <li><p>HTTP Log Collector (HLC) Logs&nbsp;(https://logs&nbsp;.&lt;region&gt;.amazonaws.com/services/collector/event) — for JSON events, ideal for migrating existing log pipelines.&nbsp;</p> </li> 
</ul> 
<ul> 
 <li><p>ND-JSON Logs&nbsp;(https://logs.&lt;region&gt;.amazonaws.com/ingest/bulk) — for newline-delimited JSON, where each line is an independent log event. Perfect for high-volume streaming and bulk log ingestion.&nbsp;</p> </li> 
</ul> 
<ul> 
 <li><p>Structured JSON Logs&nbsp;(https://logs&nbsp;.&lt;region&gt;.amazonaws.com/ingest/json) — Send a single JSON object or a JSON array of objects.</p> </li> 
</ul> 
<ul> 
 <li><p>OpenTelemetry&nbsp;Logs&nbsp;(https://logs&nbsp;.&lt;region&gt;.amazonaws.com/v1/logs) — for OTLP-formatted logs in JSON or&nbsp;Protobuf&nbsp;encoding to CloudWatch.</p> </li> 
</ul> 
<p>To enable the HLC endpoint,&nbsp;navigate to&nbsp;CloudWatch Settings in the AWS Console and generate an API key.&nbsp;CloudWatch creates the necessary IAM user with service-specific credentials and permissions. API keys can be configured with&nbsp;expiration&nbsp;periods of 1, 5, 30, 90, or&nbsp;365 days. Customers must enable bearer token authentication on each log group before it can accept logs, which&nbsp;protects from&nbsp;unintended ingestion. Customers can use service control policies to block the creation of service-specific credentials.</p> 
<p>These endpoints are available in the following AWS Regions: US East (N. Virginia), US West (N. California), US West (Oregon), and US East (Ohio). To learn more about the HLC endpoint and security best practices, refer to the&nbsp;<a href="https://docs.aws.amazon.com/AmazonCloudWatch/latest/logs/CWL_HTTP_Endpoints.html" target="_blank">CloudWatch Logs Documentation</a>.&nbsp;</p>
