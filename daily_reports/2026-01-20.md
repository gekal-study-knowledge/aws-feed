## AWS What's New

### SageMaker Unified Studio adds support for cross-Region and IAM role-based subscriptions

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/01/sagemaker-unified-studio-adds-cross-region-iam/
- **Published**: 2026-01-20

<p>Amazon SageMaker Unified Studio now supports cross-Region subscriptions and IAM role-based subscriptions for simple and flexible data access and governance. With cross-Region support, you can subscribe to AWS Glue tables and views, as well as Amazon Redshift tables and views published in a different AWS Region than your project. This capability helps break down data silos and enable better collaboration across your organization by allowing teams to access curated data assets from any AWS Region without manual replication.<br /> <br /> Additionally, you can now discovery and request access to data through IAM-role based subscriptions. This allows you to request access to data without requiring a SageMaker Unified Studio project, eliminating the project intermediary layer and simplifying access to data through IAM roles.<br /> <br /> To get started with cross-Region subscriptions, log into SageMaker Unified Studio, or use the Amazon DataZone API, SDK, or AWS CLI. IAM role-based subscriptions are available via Amazon DataZone API and SDK. These new APIs for cross-Region subscriptions and IAM role-based access are available in all <a href="https://docs.aws.amazon.com/sagemaker-unified-studio/latest/adminguide/supported-regions.html">AWS Regions where SageMaker Unified Studio</a> is supported. To learn more, see the SageMaker Unified Studio <a href="https://docs.aws.amazon.com/sagemaker-unified-studio/latest/userguide/grant-access-to-unmanaged-asset.html">user guide</a>.</p>

### Amazon Aurora and RDS for PostgreSQL, MySQL and MariaDB now support r8g, r7g, and r7i database instances in additional AWS Regions

- **Link**: https://aws.amazon.comabout-aws/whats-new/2026/01/amazon-aurora-rds-r8g-r7g-r7i-instances-additional-regions/
- **Published**: 2026-01-20

<p>AWS Graviton4-based R8g database instances are now generally available for Amazon Aurora (MySQL and PostgreSQL compatibility) and Amazon RDS for PostgreSQL, MySQL, and MariaDB in additional Asia Pacific regions (Hong Kong, Osaka, and Jakarta). R8G instances are now supported for Amazon Aurora with MySQL compatibility and Amazon RDS for PostgreSQL, MySQL, and MariaDB in Asia Pacific (Seoul and Singapore), and Canada (Central) regions, expanding on the previous launch of R8g support for Amazon Aurora with PostgreSQL compatibility in these three regions. Additionally, Amazon Aurora with MySQL and PostgreSQL compatibility now also supports R7i database instances in Asia Pacific (Hyderabad) and R7g database instances in Africa (Cape Town).<br /> <br /> AWS Graviton4-based instances provide up to 40% performance improvement and up to 29% price/performance improvement for on-demand pricing over Graviton3-based instances of equivalent sizes on Amazon Aurora and Amazon RDS databases, depending on database engine, version, and workload. Built on the AWS Nitro System, the new R8g database instances introduce 24xlarge and 48xlarge sizes, delivering up to 192 vCPUs, an 8:1 ratio of memory to vCPU with the latest DDR5 memory, up to 50Gbps enhanced networking bandwidth, and up to 40Gbps of bandwidth to Amazon Elastic Block Store (Amazon EBS).<br /> <br /> You can easily launch R8g, R7g, or R7i database instances through the&nbsp;<a href="https://console.aws.amazon.com/rds/home" target="_blank">Amazon RDS Management Console</a>&nbsp;or by using the&nbsp;<a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/Aurora.CreateInstance.html" target="_blank">AWS Command Line Interface</a>&nbsp;(CLI). For detailed information about specific engine versions that support these database instance types, please refer to the&nbsp;<a href="https://docs.aws.amazon.com/AmazonRDS/latest/AuroraUserGuide/Concepts.DBInstanceClass.SupportAurora.html" target="_blank">Aurora&nbsp;</a>and&nbsp;<a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/Concepts.DBInstanceClass.Support.html" target="_blank">RDS</a>&nbsp;documentation.&nbsp;For complete information on pricing and regional availability, please refer to the Amazon RDS&nbsp;<a href="https://aws.amazon.com/rds/pricing/" target="_blank">pricing page</a>.</p>
