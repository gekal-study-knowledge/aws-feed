# AWS Updates - 2026-01-21

## AWS What's New

### AWS Transfer Family Terraform module now supports web apps

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/01/aws-transfer-family-terraform-webapps
- **Published**: 2026-01-21

<p>You can now use the&nbsp;<a href="https://github.com/aws-ia/terraform-aws-transfer-family" target="_blank">AWS Transfer Family Terraform module</a>&nbsp;to deploy Transfer Family web apps, which enable end users to transfer files to and from Amazon S3 over a web interface. This release streamlines centralized provisioning of web apps with federated authentication and user access controls, enabling consistent, repeatable deployments through infrastructure as code.<br /> <br /> With Transfer Family web apps, you can provide your workforce with a fully managed, branded web portal to browse, upload, and download data in S3. In a single deployment, this module allows you to programmatically provision your web apps that authenticate users through AWS IAM Identity Center using your existing identity provider and Amazon S3 Access Grants for fine-grained user permissions. An included&nbsp;<a href="https://github.com/aws-ia/terraform-aws-transfer-family/tree/v0.5.0/examples/sample-web-app" target="_blank">end-to-end example</a>&nbsp;shows you how to assign and optionally create IAM Identity Center users and groups, configure S3 Access Grants, set up the web app, and enable security auditing through Amazon CloudTrail.<br /> <br /> You can get started by downloading the new module from the&nbsp;<a href="https://registry.terraform.io/modules/aws-ia/transfer-family/aws/latest/submodules/transfer-web-app" target="_blank">Terraform Registry</a>. To learn more about Transfer Family web apps, visit the&nbsp;<a href="https://docs.aws.amazon.com/transfer/latest/userguide/web-app.html" target="_blank">user guide</a>. To see all the regions where Transfer Family web apps is available, visit the&nbsp;<a href="https://docs.aws.amazon.com/transfer/latest/userguide/web-app.html#webapp-regions" target="_blank">AWS Region table</a>.</p>
