# AWS Updates - 2026-02-17

## AWS What's New

### Amazon Connect now includes agent time-off requests in draft schedules

- **Link**: https://aws.amazon.com/about-aws/whats-new/2025/02/amazon-connect-time-off-draft-schedules
- **Published**: 2026-02-17

<p>Amazon Connect now includes agent time-off requests in draft schedules, making it easier for you to view why an agent was not scheduled on a particular day or part of the day. For example, when generating schedules for next month, you can see that an agent who typically works Monday to Friday wasn't scheduled for the first week because they're on leave without needing to check the published schedules or troubleshooting configuration as to why agent was not scheduled. This launch helps schedulers quickly identify coverage gaps and adjust schedules before publishing them to agents.<br /> <br /> This feature is available in all <a href="https://docs.aws.amazon.com/connect/latest/adminguide/regions.html#optimization_region">AWS Regions</a> where Amazon Connect agent scheduling is available. To learn more about Amazon Connect agent scheduling, click <a href="https://docs.aws.amazon.com/connect/latest/adminguide/forecasting-capacity-planning-scheduling.html">here</a>.</p>
