# AWS Updates - 2026-02-26

## AWS What's New

### Amazon SNS now supports push notifications in the Europe (Spain) Region

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/02/amazon-sns-push-expansion-spain/
- **Published**: 2026-02-26

<p><a href="https://aws.amazon.com/sns/" target="_blank">Amazon Simple Notification Service (Amazon SNS)</a> now supports sending push notifications in the AWS Europe (Spain) Region.&nbsp;</p> 
<p>Amazon SNS is a fully managed pub/sub service that provides message delivery to multiple endpoints, including AWS Lambda, Amazon SQS, Amazon Data Firehose, HTTP, SMS (via AWS End User Messaging), push notifications, and email. With this launch,&nbsp;customers&nbsp;in the Europe (Spain) Region&nbsp;can use Amazon SNS to send push notifications to the following supported push notification services:&nbsp;Amazon Device Messaging (ADM), Apple Push Notification Service (APNs), Baidu Cloud Push (Baidu), Firebase Cloud Messaging (FCM), Microsoft Push Notification Service for Windows Phone (MPNS), and Windows Push Notification Services (WNS).&nbsp;</p> 
<p>With this expansion, Amazon SNS now supports sending push notifications from 25 regions. For the full list of regions from which you can send push notifications, see <a target="_blank"></a><a href="https://docs.aws.amazon.com/sns/latest/dg/sns-mobile-push-supported-regions.html" target="_blank">Supported Regions and Countries</a> in&nbsp;the Amazon SNS Developer Guide.</p> 
<p>For more information, see the <a href="https://docs.aws.amazon.com/sns/latest/dg/sns-mobile-application-as-subscriber.html" target="_blank">Amazon SNS push notifications documentation</a>.</p>
