# AWS Updates - 2026-01-14

## AWS What's New

### Enhanced Transactions view now available in AWS Billing Console

- **Link**: https://aws.amazon.com/about-aws/whats-new/2026/01/enhanced-transactions-view-aws-billing-console
- **Published**: 2026-01-14

<p>AWS announces significant improvements to the Transactions view in the AWS Billing and Cost Management Console’s Payments page, delivering faster performance, simplified payment reconciliation, and improved data accuracy. The enhanced view provides customers with a unified interface to manage all their financial transactions, improving visibility and reducing the time spent on payment tracking.<br /> <br /> The enhanced view delivers improved performance, with pages loading in mili seconds instead of minutes. Even customers with tens of thousands of transactions can now access their complete transaction history without timeouts. The enhanced view introduces new capabilities including comprehensive balance tracking, clear transaction status indicators, and advanced filtering options. Key improvements include consolidated visibility into invoice statuses, clear +/- indicators for amounts owed versus funds available, and the ability to view records in a single view without performance impact. For organizations using <a href="https://aws.amazon.com/blogs/aws/new-aws-billing-transfer-for-centrally-managing-aws-billing-and-costs-across-multiple-organizations/" target="_blank">Billing Transfer</a>, the new "Usage Consolidation Account" column makes it easier to track transactions across multiple accounts.<br /> <br /> This feature was made available to all customers on January 12, 2026, in all AWS commercial regions.<br /> <br /> To learn more about managing your transactions, visit the <a href="https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/view-payment-info.html" target="_blank">AWS Billing and Cost Management documentation.</a> For additional information about managing your AWS payments and billing, see the <a href="https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/billing-what-is.html" target="_blank">AWS Billing Console User Guide</a>.</p>
