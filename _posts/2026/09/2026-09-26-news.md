## AWS What's New

### AWS DataSync launches a monitoring dashboard for tracking task executions across your account

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/09/datasync-monitoring-dashboard](https://aws.amazon.com/about-aws/whats-new/2026/09/datasync-monitoring-dashboard)
- **Published**: 2026-09-26 00:24:00
- **Fetched**: 2026-09-26 04:09:49

<div class="entry-summary">
<p>AWS DataSync now provides a monitoring dashboard in the DataSync console that gives you visibility into your data transfers across your account. For each task execution, you can see its status, data and file transfer rates, duration, and the total data and files transferred.&nbsp;You can filter executions by status, task, task mode, execution ID, or start time to focus on a specific set of runs. The dashboard summarizes the filtered results, including the number of successful and failed executions, and the cumulative data and files transferred, grouped by task. To troubleshoot issues, you can select a failed execution to view its errors. The dashboard also displays counts of your configured tasks, locations, and agents, along with real-time total transfer rates.</p>
<p>Previously, monitoring multiple transfers required reviewing each execution individually or building custom Amazon CloudWatch dashboards. Now you can monitor the health, performance, and progress of concurrent transfers from a single view. This is useful for large migrations and recurring transfers that run many tasks at once.</p>
<p>The AWS DataSync dashboard is available at no additional cost in all commercial AWS Regions and the AWS GovCloud (US) Regions where AWS DataSync is available. To view your dashboard, go to the <a href="https://www.google.com/url?sa=t&amp;source=web&amp;rct=j&amp;opi=89978449&amp;url=CAESVwHrOzAV20j8Wk9vTsmbIbYkRAmlzPqFHALrq6V60lbYjxzHw5x2zbIj319NQT3Omkeu_ddZIwedAWPfNk9FCqq2KWuwOIO-dn4eS5n6lZZW4uQyV6vV9w&amp;ved=2ahUKEwjR4Z__g4qXAxV7FDQIHVs0I7EQFnoECB4QAQ&amp;uoh=2&amp;usg=AOvVaw3L5ZM1L-1k3SwMWi6qm9p5">AWS DataSync console</a>. To learn more about DataSync, visit the <a href="https://docs.aws.amazon.com/datasync/latest/userguide/what-is-datasync.html">AWS DataSync User Guide</a>.</p>
</div>
