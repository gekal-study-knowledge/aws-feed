### AWS DataSync launches a monitoring dashboard for tracking task executions across your account

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/09/datasync-monitoring-dashboard](https://aws.amazon.com/about-aws/whats-new/2026/09/datasync-monitoring-dashboard)
- **Published**: 2026-09-26 00:24:00
- **Fetched**: 2026-09-26 04:09:49

<div class="entry-summary">
<p>AWS DataSync now provides a monitoring dashboard in the DataSync console that gives you visibility into your data transfers across your account. For each task execution, you can see its status, data and file transfer rates, duration, and the total data and files transferred.&nbsp;You can filter executions by status, task, task mode, execution ID, or start time to focus on a specific set of runs. The dashboard summarizes the filtered results, including the number of successful and failed executions, and the cumulative data and files transferred, grouped by task. To troubleshoot issues, you can select a failed execution to view its errors. The dashboard also displays counts of your configured tasks, locations, and agents, along with real-time total transfer rates.</p>
<p>Previously, monitoring multiple transfers required reviewing each execution individually or building custom Amazon CloudWatch dashboards. Now you can monitor the health, performance, and progress of concurrent transfers from a single view. This is useful for large migrations and recurring transfers that run many tasks at once.</p>
<p>The AWS DataSync dashboard is available at no additional cost in all commercial AWS Regions and the AWS GovCloud (US) Regions where AWS DataSync is available. ### AWS IAM outbound identity federation now supports interface VPC endpoints for OIDC discovery

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/09/aws-sts-vpc-oidc/](https://aws.amazon.com/about-aws/whats-new/2026/09/aws-sts-vpc-oidc/)
- **Published**: 2026-09-26 02:54:00
- **Fetched**: 2026-09-26 08:02:33

<div class="entry-summary">
<p><a href="https://aws.amazon.com/identity/federation/outbound-federation/">AWS Identity and Access Management (IAM) outbound identity federation</a> now supports Amazon Virtual Private Cloud (VPC) endpoints for the OpenID Connect (OIDC) discovery APIs. You can now access the OIDC discovery metadata and JSON Web Key Set (JWKS) verification key endpoints from within your VPC using <a href="https://aws.amazon.com/privatelink/">AWS PrivateLink</a>, without requiring traffic to traverse the public internet.</p>
<p>IAM outbound identity federation eliminates the need to use long-lived credentials when your AWS workloads access external services. Instead, your workloads request short-lived JSON Web Tokens (JWTs) from AWS Security Token Service (AWS STS). External services verify these tokens using public verification keys and metadata available at OIDC discovery endpoints. Previously, the OIDC discovery endpoints were only reachable over the public internet, so a verifying workload running in a VPC without internet access could not retrieve them. With this launch, you can create an interface VPC endpoint to reach these endpoints privately, keeping the verification key retrieval traffic within the AWS network. This capability helps you meet network security requirements for workloads that operate in VPCs with restricted internet access, while still enabling external services to verify JWTs.</p>
<p>This feature is available in all commercial AWS Regions, the AWS GovCloud (US) Regions, and China Regions. There is no additional charge for this feature beyond standard <a href="https://aws.amazon.com/privatelink/pricing/">AWS PrivateLink pricing</a>. To learn more, see the <a href="https://docs.aws.amazon.com/IAM/latest/UserGuide/reference_sts_oidc_vpc_endpoint_create.html">IAM User Guide</a>.</p>
</div>

### Amazon Transcribe adds customer-managed KMS keys for custom resources

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-transcribe/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-transcribe/)
- **Published**: 2026-09-26 04:19:00
- **Fetched**: 2026-09-26 08:02:33

<div class="entry-summary">
<p>Amazon Transcribe now lets you encrypt your custom vocabularies, custom vocabulary filters, and custom language models at rest with a customer-managed AWS KMS key that you own and control.</p>
<p>Previously, these custom resources were always encrypted with an AWS owned key. Now you can supply your own symmetric AWS KMS key when you create or update these resources, so the artifacts Transcribe stores on your behalf are encrypted under a key in your account. If you do not provide a key, your resources continue to be encrypted with an AWS owned key—no action is required unless you opt in.</p>
<p>With a customer-managed key, you control key permissions and decide exactly which principals and services can encrypt and decrypt your custom resources. Every use of your key is logged in AWS CloudTrail, giving you a full audit trail for compliance and monitoring. You can also disable the key or transition resources to a different key to revoke access on your own schedule.</p>
<p>This feature is available in all AWS Regions where Amazon Transcribe is offered. To learn more, see <a href="https://docs.aws.amazon.com/transcribe/latest/dg/what-is.html">Amazon Transcribe Developer Guide</a>.</p>
</div>
