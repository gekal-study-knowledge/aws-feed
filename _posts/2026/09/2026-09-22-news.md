### Amazon ECS now provides real-time deployment observability in the AWS Management Console

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-ecs-console-deployment-observability/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-ecs-console-deployment-observability/)
- **Published**: 2026-09-22 05:05:00
- **Fetched**: 2026-09-22 09:32:46

<div class="entry-summary">
<p><a href="https://aws.amazon.com/ecs/">Amazon Elastic Container Service</a> (Amazon ECS) now provides real-time service deployment observability in the Amazon ECS Console for native Linear, Canary, and Blue/Green deployment strategies. With this launch, deployment monitoring and troubleshooting come together in one place in the console, so you can track deployment progress, monitor health, and diagnose failures without switching between tools.</p>
<p>Real-time service deployment observability includes a live deployment timeline that narrates each service deployment as it happens, showing every deployment phase, service events, and task launch and termination progress, always reflecting the current state. As a deployment moves forward, you can follow the traffic shift distribution across your source and target revisions and see the current lifecycle stage at a glance, whether it is scaling up green tasks, waiting on a lifecycle hook, or sitting through bake time. Deployment health signals that you would otherwise gather from separate tools now sit alongside the timeline: circuit breaker status with live task failure and threshold tracking, deployment alarm state, container and load-balancer health checks, and lifecycle hook status. When something goes wrong, failed tasks surface right in the timeline with diagnostic context and deep links to services such as AWS CloudTrail, so you can pinpoint the root cause and act on it quickly.
 <br />
 <br />
 These capabilities are available at no additional charge in all AWS commercial Regions, and AWS GovCloud (US) <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">Regions</a> for all Amazon ECS services using the Amazon ECS native Linear, Canary, and Blue/Green deployment types. To get started, navigate to any Amazon ECS service in the <a href="https://console.aws.amazon.com/ecs">Amazon ECS Console</a> and select the Deployments tab.</p>
</div>

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/09/security-hub-ai-inventory-azure-support/](https://aws.amazon.com/about-aws/whats-new/2026/09/security-hub-ai-inventory-azure-support/)

This expansion extends Security Hub's existing self-hosted discovery capabilities beyond AWS, enabling central security teams to gain a continuously updated, organization-wide view of AI assets and their security posture across multi-cloud environments.</p>

### Amazon Route 53 Resolver is now generally available on second-generation AWS Outposts racks

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/09/route-53-resolver-gen2-outposts/](https://aws.amazon.com/about-aws/whats-new/2026/09/route-53-resolver-gen2-outposts/)
- **Published**: 2026-09-22 17:00:00
- **Fetched**: 2026-09-23 07:41:24

<div class="entry-summary">
<p>Amazon Route 53 Resolver is now generally available on second-generation AWS Outposts, providing local, managed recursive DNS resolution directly on your Outpost. DNS queries from workloads running on your Outpost are resolved locally, reducing latency and eliminating the need to traverse the Service Link to reach the parent AWS Region. Route 53 Resolver maintains cached DNS records during Service Link disconnections, ensuring continuous DNS resolution even during connectivity interruptions. Route 53 Resolver runs entirely on AWS-managed infrastructure built into every second-generation Outpost, eliminating the need for customer compute capacity.</p>
<p>Route 53 Resolver is enabled by default on multi-rack second-generation Outposts. Customers who prefer to manage their own DNS resolution can opt out at any time by contacting AWS Support.</p>
<p>Route 53 Resolver on second-generation Outposts is available in all AWS Regions where second-generation Outposts are supported. All customers, including current preview customers, receive a 91-day free trial through December 21, 2026. Starting December 22, 2026, the service is priced at $0.65 per Outpost rack per hour. To get started, see the <a href="https://docs.aws.amazon.com/Route53/latest/DeveloperGuide/outpost-resolver.html" rel="noopener noreferrer" target="_blank">Route 53 Resolver on Outposts documentation</a>. For pricing details, see <a href="https://aws.amazon.com/route53/pricing/" rel="noopener noreferrer" target="_blank">Amazon Route 53 pricing</a>.</p>
</div>

### AWS Glue Data Quality delivers context-specific rule recommendations in seconds

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/09/glue-data-quality-rule-recommendations/](https://aws.amazon.com/about-aws/whats-new/2026/09/glue-data-quality-rule-recommendations/)
- **Published**: 2026-09-22 17:00:00
- **Fetched**: 2026-09-23 07:41:24

<div class="entry-summary">
<p>AWS Glue Data Quality now generates data quality rules in seconds, reducing the time to establish data quality checks for your tables in the AWS Glue Data Catalog. You get a ready-to-use set of rules with full coverage across every column, with no manual setup—so you can move from raw data to trusted data faster while authoring pipelines.</p>
<p>This is delivered through a new Advanced mode for rule recommendations, in which AWS Glue Data Quality uses generative AI to detect the intent behind your data and proposes business-relevant rules that reflect how your data is used. You can use this Advanced mode to bootstrap rules for a newly onboarded dataset or establish baseline checks across a large data lake without hand-writing each rule. You review the recommended rules, adjust as needed, and save them as a ruleset to begin monitoring immediately.</p>
<p>Advanced mode is available in the following AWS Regions: Asia Pacific (Melbourne, Osaka, Sydney, Tokyo), Canada (Central), Europe (Frankfurt, Ireland, London, Milan, Paris, Spain, Stockholm, Zurich), US East (N. Virginia, Ohio), and US West (N. California, Oregon).</p>
<p>To get started, see the <a href="https://docs.aws.amazon.com/glue/latest/dg/glue-data-quality.html">AWS Glue Data Quality documentation</a>.</p>
