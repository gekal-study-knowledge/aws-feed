### Amazon MWAA supports Apache Airflow version 3.3.1

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-mwaa-apache-airflow-3-3-1/](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-mwaa-apache-airflow-3-3-1/)
- **Published**: 2026-09-02 00:00:00
- **Fetched**: 2026-09-02 05:28:23

<div class="entry-summary">
<p>Amazon Managed Workflows for Apache Airflow (MWAA) now supports Apache Airflow version 3.3.1, the latest release of the popular open-source workflow orchestration framework. Amazon MWAA is a managed orchestration service for Apache Airflow that makes it easier to set up and operate end-to-end data pipelines in the cloud.</p> 
<p>Apache Airflow 3.3 introduces stateful tasks and multi-language support. With the new Task and Asset State Store, tasks can now persist durable state across retries and reruns, enabling cursor tracking and crash-safe reconnection to long-running jobs. The Language Task SDK (experimental) lets teams write task logic in Java or Go while keeping orchestration in Python. Additional improvements include expanded asset partitioning, pluggable retry policies, and bulk actions for DAG runs and task instances. Apache Airflow 3.3.1 also delivers stability, security, and UI improvements on top of these capabilities.</p> 
<p>You can launch a new Apache Airflow 3.3.1 environment on Amazon MWAA, or upgrade from 3.2 or later, with a few clicks in the <a href="https://console.aws.amazon.com/mwaa/home">AWS Management Console</a> in all currently supported <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">Amazon MWAA regions</a>. To learn more about Apache Airflow 3.3.1, visit the <a href="https://docs.aws.amazon.com/mwaa/latest/userguide/what-is-mwaa.html">Amazon MWAA documentation</a> and the <a href="https://airflow.apache.org/docs/apache-airflow/3.3.1/release_notes.html#airflow-3-3-1-2026-08-12">Apache Airflow 3.3.1 change log</a> in the Apache Airflow documentation.</p> 
<p><i>Apache, Apache Airflow, and Airflow are either registered trademarks or trademarks of the <a href="https://www.apache.org/">Apache Software Foundation</a> in the United States and/or other countries.</i></p>
</div>

### Amazon Connect Customer dashboards now support compact mode

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/09/connect-dashboards-compact-mode/](https://aws.amazon.com/about-aws/whats-new/2026/09/connect-dashboards-compact-mode/)
- **Published**: 2026-09-02 02:00:00
- **Fetched**: 2026-09-02 05:28:23

<div class="entry-summary">
<p>Amazon Connect Customer now offers compact mode on the analytics dashboards, increasing data density so supervisors can see more of their operational data without scrolling. Compact mode reduces widget size, font, and minimizes&nbsp;filters to maximize&nbsp;screen space. For example, a supervisor on a 13-inch laptop toggles compact mode, which reduces row height, enabling them to view all team agents on the widget without scrolling and spot non-adherent agents faster.</p> 
<p>Compact mode on dashboards is available in all AWS <a href="https://docs.aws.amazon.com/connect/latest/adminguide/regions.html#amazonconnect_region">regions</a> where Amazon Connect Customer is offered. To learn more about Amazon Connect Customer analytics dashboards, see the <a href="https://docs.aws.amazon.com/connect/latest/adminguide/dashboards.html">Amazon Connect Customer Administrator Guide</a>.&nbsp; To learn more about Amazon Connect Customer, visit the <a href="https://aws.amazon.com/connect/">Amazon Connect Customer website</a>.</p>
</div>

## AWS Security Bulletins

### CVE-2026-83551 - Cleartext storage of HMAC signing key in Amazon SageMaker Python SDK

- **Link**: [https://aws.amazon.com/security/security-bulletins/rss/2026-093-aws/](https://aws.amazon.com/security/security-bulletins/rss/2026-093-aws/)
- **Published**: 2026-09-02 03:21:24
- **Fetched**: 2026-09-02 05:28:24

<div class="entry-summary">
<p><b>Bulletin ID:</b> 2026-093-AWS<br /> <b>Scope:</b> AWS<br /> <b>Content Type:</b> Important (requires attention)<br /> <b>Publication Date:</b> 09/01/2026 11:00 AM PDT</p> 
<p><b>Description:</b></p> 
<p>SageMaker Python SDK's @step and @remote decorator pipeline component uses an HMAC key to protect the integrity of serialized function payloads stored in S3. We identified an issue where the HMAC secret key is stored in cleartext within pipeline definitions and accessible via the DescribePipeline API.</p> 
<p>This allows an actor with a role in that account that has permissions to invoke DescribePipeline to extract the key, create cloud-pickled payloads with valid HMACs, and overwrite S3 objects, achieving code execution in another user's pipeline execution context within the same AWS account.</p> 
<p><b>Impacted versions:</b><br /> - HMAC Configuration in SageMaker Python SDK v3 &lt; v3.11.0<br /> - HMAC Configuration in SageMaker Python SDK v2 &lt; v2.256.0</p> 
<p><b>Please refer to the article below for the most up-to-date and complete information related to this AWS Security Bulletin.</b></p>
</div>
