## AWS What's New

### Amazon RDS for PostgreSQL supports minor versions 18.7, 17.12, 16.16, 15.20, and 14.25

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-rds-postgresql-18-7-17-12-16-16-15-20-14-25/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-rds-postgresql-18-7-17-12-16-16-15-20-14-25/)
- **Published**: 2026-11-27 02:00:00
- **Fetched**: 2026-11-27 08:27:49

<div class="entry-summary">
<p><a href="https://aws.amazon.com/rds/postgresql/" rel="noopener noreferrer" target="_blank">Amazon Relational Database Service (RDS) for PostgreSQL</a> now supports the latest minor versions 18.7, 17.12, 16.16, 15.20, and 14.25. We recommend that you upgrade to the latest minor versions to address Common Vulnerabilities and Exposures (CVEs) in prior versions of PostgreSQL, and to benefit from the bug fixes and improvements added by the PostgreSQL community.</p> 
<p>You can upgrade your databases during scheduled maintenance windows using automatic minor version upgrades. To simplify operations at scale, enable automatic minor version upgrades and use the AWS Organizations <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/RDS.Maintenance.AMVU.UpgradeRollout.html" rel="noopener noreferrer" target="_blank">Upgrade Rollout Policy</a> to orchestrate multiple upgrades in phases, validating on lower-priority environments before upgrading your most critical ones. You can also use Amazon RDS Blue/Green deployments to minimize downtime for minor version upgrades. For more information, see <a href="https://docs.aws.amazon.com/AmazonRDS/latest/UserGuide/USER_UpgradeDBInstance.PostgreSQL.html" rel="noopener noreferrer" target="_blank">Upgrading RDS for PostgreSQL DB engine</a>.</p> 
<p>Amazon RDS for PostgreSQL makes it simple to set up, operate, and scale PostgreSQL deployments in the cloud. See <a href="https://aws.amazon.com/rds/postgresql/pricing/" rel="noopener noreferrer" target="_blank">Amazon RDS for PostgreSQL Pricing</a> for pricing details and regional availability. Create or update a fully managed Amazon RDS database in the <a href="https://console.aws.amazon.com/rds/" rel="noopener noreferrer" target="_blank">Amazon RDS Management Console</a> or by using the AWS Command Line Interface (CLI).</p>
</div>
