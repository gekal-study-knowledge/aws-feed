### Amazon WorkSpaces for AI agents now supports Linux and Windows 11 cloud desktops

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/11/workspaces-ai-agents-linux-windows-11](https://aws.amazon.com/about-aws/whats-new/2026/11/workspaces-ai-agents-linux-windows-11)
- **Published**: 2026-11-04 03:00:00
- **Fetched**: 2026-11-05 03:24:15

<div class="entry-summary">
<p>WorkSpaces for AI agents now supports Linux and Windows 11 cloud desktops, in addition to Windows Server. You can run each AI agent on the operating system that its workflows and applications require. Your agents can then work in the same environments that your workforce already uses, without re-platforming.&nbsp;</p> 
<p>Linux desktops give agents full root access to the operating system where many developers already build, test, and automate agentic workflows. Agents can take on developer tasks, such as running builds, tests, and scripts, within the enterprise-grade security and governance controls you already rely on. Windows 11 desktops let agents work in the enterprise applications your teams depend on every day.</p> 
<p>Linux and Windows 11 desktops have the same security and governance controls as Windows Server desktops. These include network isolation, IAM-based access, and the compliance boundaries your organization already has in place.</p> 
<p>To get started operating AI agents on WorkSpaces, visit: <a href="https://docs.aws.amazon.com/appstream2/latest/developerguide/agent-access.html">https://docs.aws.amazon.com/appstream2/latest/developerguide/agent-access.html</a>.</p>
</div>

### Amazon Connect Customer lets agents pause and resume emails

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/11/connect-pause-resume-email/](https://aws.amazon.com/about-aws/whats-new/2026/11/connect-pause-resume-email/)
- **Published**: 2026-11-04 05:15:00
- **Fetched**: 2026-11-04 07:50:10

<div class="entry-summary">
<p>Amazon Connect Customer lets agents pause emails while waiting for information or approvals, freeing them to handle higher-priority contacts and resume their work later. For example, an agent waiting for a supervisor to approve a refund can pause the email and take an incoming call. Paused time is tracked separately from active handling time, giving supervisors a more accurate view of the time agents spend working on emails.</p> 
<p>Agents can pause and resume emails directly from the Agent Workspace or Contact Control Panel (CCP) and see how long each email has been paused. Supervisors can monitor paused emails and pause duration in real time, and use flows to automatically resume or transfer emails that remain paused beyond a configured threshold.</p> 
<p>Amazon Connect Customer email pause and resume is available in the US East (N. Virginia), US West (Oregon), Africa (Cape Town), Asia Pacific (Seoul), Asia Pacific (Singapore), Asia Pacific (Sydney), Asia Pacific (Tokyo), Canada (Central), Europe (Frankfurt), and Europe (London) <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">regions</a>. To learn more and get started, please refer to the help <a href="https://docs.aws.amazon.com/connect/latest/adminguide/concepts-pause-and-resume-emails.html">documentation</a> or visit the <a href="https://aws.amazon.com/connect/">Amazon Connect Customer</a> website.</p>
</div>
