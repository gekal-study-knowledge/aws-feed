### New features for Amazon EC2 Capacity Manager

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-capacity-manager-supportability-and-fulfillment/](https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-capacity-manager-supportability-and-fulfillment/)
- **Published**: 2026-11-04 16:00:00
- **Fetched**: 2026-11-05 09:05:25

<details class="entry-summary">
<summary>詳細を表示</summary>
<p>Amazon EC2 Capacity Manager now offers real-time supportability checks and capacity fulfillment metrics. Real-time supportability checks help customers find capacity by scoring how well each instance type and Availability Zone can support a request, without launching or reserving instances. Capacity fulfillment metrics show how much capacity was delivered against the amount requested.</p> 
<p>Global enterprises that run thousands of workloads across hundreds of accounts often spread each one across multiple instance types and Availability Zones, giving Amazon EC2 more options to fulfill each request. Starting today, customers can use the supportability checks in Capacity Manager to understand which Availability Zones and instance types give them the best chance of getting the capacity they need. The check returns a High, Medium, or Low score for each option, plus an overall score. Additionally, with fulfillment metrics, customers can measure fulfillment rates across their AWS organization, accounts, Regions, and tagged workloads, with a breakdown by instance type and Availability Zone, to show how well those choices are working.</p> 
<p>Both capabilities are included with <a href="https://docs.aws.amazon.com/awssupport/latest/user/unified-operations-intro.html" rel="noopener noreferrer" target="_blank">AWS Unified Operations</a>, the AWS Support plan for global enterprises running mission-critical workloads, and are available in all commercial AWS Regions.</p>

### Amazon EC2 and VPC now display related resources for all resource types

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-vpc-related-resources-all-types/](https://aws.amazon.com/about-aws/whats-new/2026/11/ec2-vpc-related-resources-all-types/)
- **Published**: 2026-11-04 17:00:00
- **Fetched**: 2026-11-05 09:05:25

<div class="entry-summary">
<p>Amazon Elastic Compute Cloud (Amazon EC2), Amazon Virtual Private Cloud (Amazon VPC), and AWS Global View now display related resources for all resource types in their consoles. Previously, only security groups had an option to view related resources. Now you can see relationships for all EC2 and VPC resource types, including EC2 instances, Amazon Elastic Block Store (Amazon EBS) volumes, Launch Templates, Auto Scaling groups, subnets, route tables, and more. The Related Resources tab has also been moved to the console toolbar for easier access.</p>
<p>This capability helps you better understand your infrastructure dependencies and troubleshoot issues more efficiently. For example, when investigating an EC2 instance issue, you can quickly view its associated EBS volumes, security groups, subnets, and route tables without navigating between multiple console pages. Network administrators can now trace connections from a subnet to its associated route tables, network ACLs, and instances, streamlining network configuration reviews and security audits.</p>
<p>This feature is now available in all commercial AWS Regions.</p>
<p>To learn more, visit Amazon EC2 and Amazon VPC in the <a href="https://console.aws.amazon.com/" target="_blank">AWS Management Console</a>.</p>

### Amazon S3 Tables now provide a simple, cost-effective path for data lake modernization

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-s3-tables-managed-migration-hive-to-iceberg/](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-s3-tables-managed-migration-hive-to-iceberg/)
- **Published**: 2026-11-04 17:00:00
- **Fetched**: 2026-11-05 16:39:47

<details class="entry-summary">
<summary>詳細を表示</summary>
<p>Amazon S3 Tables now offer managed migration of your Apache Hive tables to Apache Iceberg. Iceberg adds ACID transactions, schema evolution, and time travel to your data lake, but moving off Hive usually means building a migration pipeline for each table, which can take weeks. You can now let S3 Tables manage your migration, resulting in query-ready Iceberg tables that stay optimized as data grows.</p> 
<p>S3 Tables validate, convert, and copy your data while production workloads keep running. To lower migration risk, you can review each step, sync destination tables with source changes as often as you need, or roll back to your source data. You pay only for the data that the job copies, with no charge for the Hive-to-Iceberg conversion, and source objects in S3 Intelligent-Tiering stay in their current access tier. If your tables use Snappy compression, S3 Tables recompress them to Zstandard (ZSTD) and compact them, which reduces storage and object count and improves query performance.</p> 
<p>To get started, visit the AWS Management Console or use the Amazon S3 Tables migration APIs. A <a href="https://github.com/aws/agent-toolkit-for-aws/tree/main/skills/specialized-skills/analytics-skills/migrating-hive-tables-to-s3-tables" rel="noopener noreferrer" target="_blank">migration skill</a> is also available in the Agent Toolkit for AWS to help AI agents orchestrate the workflow autonomously.&nbsp;At launch, S3 Tables managed migration supports AWS Glue-registered Hive tables stored in Parquet format within the same AWS account and AWS Region. It is available in the following AWS Regions: US East (N. Virginia, Ohio), US West (Oregon), Asia Pacific (Mumbai, Singapore, Sydney, Tokyo), Europe (Frankfurt, Ireland, Stockholm). For pricing information visit <a href="https://aws.amazon.com/s3/pricing/" rel="noopener noreferrer" style="background-color: rgb(255,255,255);" target="_blank">Amazon S3 pricing</a>. To learn more, see the Amazon S3 Tables <a href="https://aws.amazon.com/s3/features/tables/" rel="noopener noreferrer" style="background-color: rgb(255,255,255);" target="_blank">overview page</a>, <a href="https://docs.aws.amazon.com/AmazonS3/latest/userguide/s3-tables-migrate.html" rel="noopener noreferrer" style="background-color: rgb(255,255,255);" target="_blank">documentation</a>, and <a href="https://aws.amazon.com/blogs/aws/amazon-s3-tables-now-offer-managed-migration-of-apache-hive-tables-to-apache-iceberg/" rel="noopener noreferrer" style="background-color: rgb(255,255,255);" target="_blank">AWS News Blog</a>.</p>
</details>
