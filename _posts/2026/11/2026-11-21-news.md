# AWS Updates - 2026-11-21

## AWS Security Bulletins

### CVE-2026-133199 - Incorrect privilege assignment on reused e-mail addresses or group names in AWS ssosync

- **Link**: [https://aws.amazon.com/security/security-bulletins/rss/2026-194-aws/](https://aws.amazon.com/security/security-bulletins/rss/2026-194-aws/)
- **Published**: 2026-11-21 01:41:29
- **Fetched**: 2026-11-21 02:29:54

<div class="entry-summary">
<p><b>Bulletin ID:</b> 2026-194-AWS<br /> <b>Publication Date:</b> 11/20/2026 08:30 AM PST</p> 
<p><b>Description:</b></p> 
<p>Incorrect privilege assignment in the user and group reconciliation logic in AWS ssosync before 2.9.5 might allow an authenticated remote user who is assigned a reused Google Workspace e-mail address or group name to inherit the IAM Identity Center group memberships and permission set assignments of a previously synchronized, unrelated identity, via automatic synchronization of that Google Workspace account or group.</p> 
<p><b>Impacted versions:</b> &lt; 2.9.5</p>
