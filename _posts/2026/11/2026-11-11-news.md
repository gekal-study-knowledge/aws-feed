## AWS Security Bulletins

### CVE-2026-125271 - AWS API MCP Server Security Policy Bypass via Incorrect Operation Name Normalization

- **Link**: [https://aws.amazon.com/security/security-bulletins/rss/2026-176-aws/](https://aws.amazon.com/security/security-bulletins/rss/2026-176-aws/)
- **Published**: 2026-11-11 01:42:37
- **Fetched**: 2026-11-11 02:26:42

<div class="entry-summary">
<p><b>Bulletin ID:</b> 2026-176-AWS<br /> <b>Publication Date:</b> 11/10/2026 08:30 AM PST</p> 
<p><b>Description:</b></p> 
<p>We identified CVE-2026-125271 of AWS API MCP Server. The server normalized operation names incorrectly before comparing them to the operator ' s security policy, so operations whose names contain consecutive capital letters never matched a correctly written denyList or elicitList entry. This might allow an actor to execute AWS API operations that the operator's security policy was configured to deny or require elicitation for.</p> 
<p><b>Impacted versions:</b> &gt;= 0.2.13 AND &lt; 1.5.1</p>

</div>
