### CVE-2026-107783 - Insertion of sensitive information into log file in AWS Tools for PowerShell

- **Link**: [https://aws.amazon.com/security/security-bulletins/rss/2026-132-aws/](https://aws.amazon.com/security/security-bulletins/rss/2026-132-aws/)
- **Published**: 2026-10-10 00:56:44
- **Fetched**: 2026-10-10 01:51:34

<div class="entry-summary">
<p><b>Bulletin ID:</b> 2026-132-AWS
 <br />
 <b>Scope:</b> AWS
 <br />
 <b>Content Type:</b> Important (requires attention)
 <br />
 <b>Publication Date:</b> 10/09/2026 08:30 AM PDT</p>
<p><b>Description:</b></p>
<p>AWS Tools for PowerShell V5 lets developers and administrators manage their AWS services from the PowerShell scripting environment. We identified CVE-2026-107783, where insertion of sensitive information into log file in AWS Tools for PowerShell before 5.0.306 might allow local users to recover an IAM user's cleartext AWS Management Console password from command output and log artifacts.</p>
<p><b>Impacted versions:</b> &lt;= v5.0.305</p>
<p><b>Please refer to the article below for the most up-to-date and complete information related to this AWS Security Bulletin.</b></p>
