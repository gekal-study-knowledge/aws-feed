# AWS Updates - 2026-10-29

## AWS What's New

### Amazon EKS Auto Mode now supports Kubernetes Gateway API

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-eks-auto-mode-kubernetes-gateway-api/](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-eks-auto-mode-kubernetes-gateway-api/)
- **Published**: 2026-10-29 02:33:00
- **Fetched**: 2026-10-29 04:18:31

<div class="entry-summary">
<p>Amazon EKS Auto Mode now supports the Kubernetes Gateway API, giving customers a standard, portable way to define how traffic reaches their applications. Customers can configure application load balancing using Gateway and HTTPRoute resources, and EKS Auto Mode provisions and manages the underlying AWS infrastructure automatically.</p> 
<p>With this launch, EKS Auto Mode customers can adopt the next-generation Kubernetes traffic management standard without installing or configuring a separate controller. Capabilities include HTTP and gRPC routing, cross-namespace traffic routing for multi-team environments, weighted traffic splitting, header-based routing, and automatic TLS certificate discovery through AWS Certificate Manager. Existing workloads using Ingress resources continue to work alongside Gateway API resources.</p> 
<p>To get started, see the <a href="https://docs.aws.amazon.com/eks/latest/userguide/auto-configure-gateway-api.html">Amazon EKS documentation</a>. Gateway API support is included as part of EKS Auto Mode and is available in all AWS Regions where EKS Auto Mode is supported. Standard charges apply for the AWS load balancing resources provisioned.</p>
</div>

## AWS Security Bulletins

### CVE-2026-118029 - Unverified ownership of the default Athena query result location in AWS SDK for pandas

- **Link**: [https://aws.amazon.com/security/security-bulletins/rss/2026-153-aws/](https://aws.amazon.com/security/security-bulletins/rss/2026-153-aws/)
- **Published**: 2026-10-29 00:40:38
- **Fetched**: 2026-10-29 04:18:33

<div class="entry-summary">
<p><b>Bulletin ID:</b> 2026-153-AWS<br /> <b>Scope:</b> AWS<br /> <b>Content Type:</b> Important (requires attention)<br /> <b>Publication Date:</b> 10/28/2026 08:30 AM PDT</p> 
<p><b>Description:</b></p> 
<p>AWS SDK for pandas (awswrangler) is an open-source Python library that integrates pandas with AWS data services such as Amazon Athena, Amazon S3, and AWS Glue. We identified CVE-2026-118029 in the Athena module, where unverified ownership of the default query result location could allow a remote user to read Athena query results and tamper with result sets returned to the caller via a pre-created S3 bucket.</p> 
<p><b>Impacted versions:</b> awswrangler &lt; 3.16.1</p> 
<p><b>Please refer to the article below for the most up-to-date and complete information related to this AWS Security Bulletin.</b></p>
