### AWS HealthOmics introduces resource fallback order for Nextflow workflows

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-healthomics-resource-fallback-for-Nextflow/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-healthomics-resource-fallback-for-Nextflow/)
- **Published**: 2026-10-15 01:00:00
- **Fetched**: 2026-10-15 05:24:28

<div class="entry-summary">
<p>Today, AWS HealthOmics introduces the resource fallback directive for tasks in your Nextflow workflows, enabling you to define an ordered list of preferred accelerator types, including an option to fallback to CPU instances. Researchers and bioinformaticians can use this directive to reduce time spent diagnosing and resubmitting runs due to accelerator constraints and keep production workflows running. <a href="https://aws.amazon.com/healthomics/">AWS HealthOmics</a> is a HIPAA-eligible service that helps healthcare and life sciences customers accelerate scientific breakthroughs at scale with fully managed bioinformatics workflows. </p>
<p>With resource fallback for Nextflow workflows, you can prioritize your preferred accelerator for your task. When your preferred accelerator is unavailable, HealthOmics automatically moves through your specified alternatives in the fallback without resubmission. Each accelerator profile has a configurable timeout, giving you control over how long HealthOmics searches for that accelerator before moving to the next. Shorter timeouts help you move quickly through the fallback order, while longer timeouts increase the probability of reserving your preferred accelerator. You can also include a CPU profile as a final fallback to increase the likelihood of your task reserving an instance. </p>
<p>You can now use resource fallback for Nextflow workflows in all AWS HealthOmics Regions: US East (N. Virginia, Ohio), US West (Oregon), Europe (Frankfurt, Ireland, London), Israel (Tel Aviv), and Asia Pacific (Seoul, Singapore, Tokyo). To learn more, visit the <a href="https://docs.aws.amazon.com/omics/latest/dev/advanced-resource-configuration.html">advanced resource configuration</a>&nbsp;and <a href="https://docs.aws.amazon.com/omics/latest/dev/workflow-definition-nextflow.html#workflow-nextflow-directive-fallback">Nextflow specifics</a> documentation. </p>
</div>

### Amazon SageMaker Studio simplifies getting started for new AI/ML builders with social sign-in

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/10/sagemaker-studio-social-sign-in/](https://aws.amazon.com/about-aws/whats-new/2026/10/sagemaker-studio-social-sign-in/)
- **Published**: 2026-10-15 02:00:00
- **Fetched**: 2026-10-15 05:24:28

<details class="entry-summary">
<summary>詳細を表示</summary>
<p>Amazon SageMaker Studio now lets new customers sign up with their Google, GitHub, or Apple credentials and land inside a fully configured Studio environment - no traditional AWS account setup, no credit card, and no console navigation required.</p>
<p>Previously, new customers who discovered a model on Hugging Face or an AWS product page had to complete a multi-step AWS account creation process, provide a credit card, navigate the AWS Console to find SageMaker AI, configure an environment, and set up IAM permissions before they could begin working. With earlier launches, we reduced environment setup to twenty seconds, pre-configured model customization permissions, and introduced deep links from Hugging Face and AWS product pages so customers could land directly inside Studio with a model pre-loaded. Now, with social sign-in, new customers complete a simplified sign-up using an existing identity, receive free credits as part of the AWS Free Tier with no credit card required, and arrive inside a ready-to-use SageMaker Studio environment where they can immediately fine-tune, evaluate, and deploy foundation models. Customers can invite team members by email, and collaborators sign in with their own social credentials to access the shared Studio environment, including shared models, notebooks, and endpoints without configuring IAM users or permissions. When a project grows beyond free credits, customers can upgrade to a paid plan and set a spend limit to stay within budget. Verified customers continue to receive default GPU access to G5, G6, G6e, and G4dn instances across endpoint deployments, training jobs, and notebooks without requesting quota increases.</p>
<p>This feature is available in all AWS Commercial Regions where Amazon SageMaker Studio is supported. To get started, visit any supported model on <a href="https://huggingface.co/models"><u>Hugging Face</u></a> and select "Customize and Deploy on SageMaker AI" or "Deploy on SageMaker AI," or click Get Started from the <a href="https://aws.amazon.com/sagemaker/ai/studio/"><u>SageMaker Studio</u></a> page. To learn more, see the <a href="https://docs.aws.amazon.com/accounts/latest/reference/sign-in-new.html"><u>AWS sign-up documentation</u></a> and <a href="https://docs.aws.amazon.com/sagemaker/latest/dg/onboard-quick-start.html"><u>SageMaker Studio setup guide</u></a>.</p>
</details>

### AWS License Manager now supports license type conversions for Ubuntu Pro purchased through AWS Marketplace

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/10/aws-license-manager-conversions-ubuntu-pro-marketplace/](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-license-manager-conversions-ubuntu-pro-marketplace/)
- **Published**: 2026-10-15 02:04:00
- **Fetched**: 2026-10-15 05:24:28

<div class="entry-summary">
<p><a href="https://aws.amazon.com/license-manager/">AWS License Manager&nbsp;</a> now supports in-place upgrades for EC2 Ubuntu LTS (Long Term Support) instances to Ubuntu Pro available on AWS Marketplace. This allows customers to strengthen their security posture and meet compliance requirements without rebuilding their fleet or migrating workloads to a new instance or AMI. With an Ubuntu Pro subscription, customers receive security patches for up to 10 years — extendable to 15 years with the Legacy add-on. This coverage extends beyond the base OS to thousands of additional packages, including widely used open-source applications such as NGINX, PostgreSQL, MongoDB, and Redis. Ubuntu Pro also supports Kernel Livepatch, which applies critical kernel security fixes without rebooting to minimize downtime.</p>
<p>With this launch, customers, who have an existing Canonical Ubuntu Pro subscription through AWS Marketplace, can upgrade directly during the conversion workflow. Customers who do not yet have a subscription can subscribe to Canonical Ubuntu Pro from within the AWS License Manager console. The new feature is available in &nbsp;<a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">all commercial regions&nbsp;</a> where AWS License Manager is available.</p>
<p>To get started, navigate to the &nbsp;<a href="https://us-east-1.console.aws.amazon.com/license-manager/home?region=us-east-1#/">AWS License Manager console&nbsp;</a> and the &nbsp;<a href="https://docs.aws.amazon.com/license-manager/latest/userguide/license-asset-groups-overview.html">AWS License Manager User Guide&nbsp;</a>.&nbsp;</p>
</div>

 <br />
 <b>Publication Date:</b> 10/14/2026 11:30 AM PDT</p>
<p><b>Description:</b></p>
<p>Amazon SageMaker Python SDK is an open source library for training and deploying machine learning models on Amazon SageMaker.</p>
<p>We identified CVE-2026-110248, an issue in the git_utils.py component of Amazon SageMaker Python SDK. When a Git clone operation fails, repository credentials in subprocess error output are written to CloudWatch Logs without redaction. An authenticated remote user with access to those logs is able to obtain the plaintext credentials.</p>

 - Amazon SageMaker Python SDK V3 versions before 3.10.0</p>

### CVE-2026-110310 - RSA PKCS#1 v1.5 padding oracle via legacy envelope key format downgrade in Amazon S3 Encryption Client for .NET

- **Link**: [https://aws.amazon.com/security/security-bulletins/rss/2026-135-aws/](https://aws.amazon.com/security/security-bulletins/rss/2026-135-aws/)
- **Published**: 2026-10-15 04:48:49
- **Fetched**: 2026-10-15 05:24:30

<div class="entry-summary">
<p><b>Bulletin ID:</b> 2026-135-AWS
 <br />
 <b>Scope:</b> AWS
 <br />
 <b>Content Type:</b> Important (requires attention)
 <br />
 <b>Publication Date:</b> 10/14/2026 12:30 PM PDT</p>
<p><b>Description:</b></p>
<p>We identified CVE-2026-110310, an issue in Amazon S3 encryption client for .NET that could allow a remote user who can read encrypted objects in the S3 bucket can force a padding downgrade by altering the padding scheme recorded in an object's metadata to legacy PKCS#1 v1.5. Since this padding scheme is susceptible to the Bleichenbacher attack, the user can use a PKCS#1 v1.5 padding oracle to recover the RSA-wrapped envelope key and decrypt the object.</p>
<p><b>Impacted versions:</b> &gt;= 2.1.0; 3.0.0 to 3.2.1; 4.0.0 to 4.0.2</p>
<p><b>Please refer to the article below for the most up-to-date and complete information related to this AWS Security Bulletin.</b></p>
