### Amazon Connect Customer expands testing and simulation to validate flow action outcomes

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/10/connect-customer-validate-flow-actions/](https://aws.amazon.com/about-aws/whats-new/2026/10/connect-customer-validate-flow-actions/)
- **Published**: 2026-10-27 00:00:00
- **Fetched**: 2026-10-27 09:12:51

<div class="entry-summary">
<p>Amazon Connect Customer now enables you to validate the outcomes of your customer experience flow actions during testing and simulation. In addition to confirming that an action started, you can now verify the data it returns when it completes, such as a Lambda function response, an Amazon Lex resolved intent, or the variables set by an Agentic CX block. <p>To learn more about this feature, see <a href="https://docs.aws.amazon.com/connect/latest/adminguide/testing-simulation-observe-block.html">testing and simulation</a> in the Connect Customer administrator guide. For a complete list of testing and simulation capabilities available by AWS Region, refer to <a href="https://docs.aws.amazon.com/connect/latest/adminguide/regions.html">Availability of Connect Customer features by Region</a>. To learn more about Amazon Connect Customer, an agentic AI solution that helps enterprises deliver exceptional customer experiences, visit the <a href="https://aws.amazon.com/products/connect/customer/">Amazon Connect Customer website</a>.</p>
</div>

### Amazon WorkSpaces Core Managed Instances now supports ModifyVolume API

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-workspaces-cmi-modifyvolume/](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-workspaces-cmi-modifyvolume/)
- **Published**: 2026-10-27 03:00:00
- **Fetched**: 2026-10-27 05:52:19

<div class="entry-summary">
<p>Amazon WorkSpaces Core Managed Instances now supports the ModifyVolume API, which lets you change volume size, volume type, IOPS, or throughput in place, without detaching the volume or restarting the instance. Previously, changing storage capacity or performance on a deployed managed instance required rebuilding it.</p> 
<p>With ModifyVolume, you can increase volume size up to 16,384 GiB, switch between supported Amazon EBS volume types, adjust IOPS for gp3, io1, and io2 volumes, and modify throughput for gp3 volumes. The API supports idempotency tokens to prevent duplicate changes, and you can track progress with the Amazon EC2 DescribeVolumesModifications operation.</p> 
<p>ModifyVolume is available in all AWS Regions where Amazon WorkSpaces Core Managed Instances is available.</p> 
<p>To get started, call ModifyVolume directly, or use it through your WorkSpaces Core partner solution once available. To learn more, see <a href="https://docs.aws.amazon.com/workspaces-instances/latest/api/API_ModifyVolume.html" rel="noopener noreferrer" target="_blank">ModifyVolume</a> in the WorkSpaces Instances API Reference and <a href="https://docs.aws.amazon.com/ebs/latest/userguide/ebs-modify-volume.html#elastic-volumes-limitations" rel="noopener noreferrer" target="_blank">Limitations</a> in the Amazon EBS User Guide, or visit <a href="https://aws.amazon.com/workspaces/vdi-partners/" rel="noopener noreferrer" target="_blank">WorkSpaces Core</a>.</p>
</div>

### Amazon ECR now supports replication backfill for existing container images

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/10/replication-backfill-amazon-ecr](https://aws.amazon.com/about-aws/whats-new/2026/10/replication-backfill-amazon-ecr)
- **Published**: 2026-10-27 05:24:00
- **Fetched**: 2026-10-28 02:22:49

<div class="entry-summary">
<p>Amazon Elastic Container Registry (Amazon ECR) now supports replication backfill, enabling you to replicate existing images in your private registry to your configured replication registry destinations. Previously, replication only applied to images pushed after the replication configuration was enabled, requiring customers to manually retag images to trigger replication of preexisting images. With replication backfill, you can now replicate your full image catalog to new or existing destinations with a single API call.</p> 
<p>Replication backfill is useful when expanding to a new AWS Region, validating disaster recovery readiness, updating replication rules, or ensuring complete image catalogs exist across Regions for compliance purposes. You can run up to ten backfill jobs concurrently, monitor progress and per-image results through new APIs, and stop a job at any time without deleting images that have already been replicated.</p> 
<p>Replication backfill is available in all AWS Regions where Amazon ECR is available. To learn more, refer to the <a href="https://docs.aws.amazon.com/AmazonECR/latest/userguide/">Amazon ECR user guide</a>.&nbsp;</p>
</div>
