## AWS Security Bulletins

### CVE-2026-110812 - Deserialization of untrusted data in the Gremlin graph-import path in Amazon Neptune

- **Link**: [https://aws.amazon.com/security/security-bulletins/rss/2026-136-aws/](https://aws.amazon.com/security/security-bulletins/rss/2026-136-aws/)
- **Published**: 2026-10-16 01:41:28
- **Fetched**: 2026-10-16 02:58:15

<div class="entry-summary">
<p><b>Bulletin ID:</b> 2026-136-AWS
 <br />
 <b>Scope:</b> AWS
 <br />
 <b>Content Type:</b> Important (requires attention)
 <br />
 <b>Publication Date:</b> 10/15/2026 09:30 AM PDT</p>
<p><b>Description:</b></p>
<p>Amazon Neptune is a fully managed graph database service. We identified CVE-2026-110812, an issue in Apache TinkerPop related to Gremlin functionality used by Amazon Neptune. Under certain conditions, an authenticated principal with Neptune data-plane (query) permissions could submit a request that causes the query engine to process untrusted input unsafely, which could lead to unintended activity within the query engine environment. This issue has been addressed in the engine versions listed below; we recommend customers upgrade.</p>
<p><b>Impacted versions:</b> &gt;=1.2.0.0</p>
<p><b>Please refer to the article below for the most up-to-date and complete information related to this AWS Security Bulletin.</b></p>
</div>
