# AWS Updates - 2026-04-16

## AWS What's New

### Claude Opus 4.7 is now available in Amazon Bedrock

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/04/claude-opus-4.7-amazon-bedrock/](https://aws.amazon.com/about-aws/whats-new/2026/04/claude-opus-4.7-amazon-bedrock/)
- **Published**: 2026-04-16 12:00:00

<p>Amazon Bedrock, the platform for building AI applications and agents at production scale, now offers Claude Opus 4.7--&nbsp;Anthropic's&nbsp;most capable Opus model to date&nbsp;--&nbsp;delivering meaningful improvements across agentic coding,&nbsp;professional&nbsp;work, and long-running tasks for developers and enterprises building production AI applications.&nbsp;</p> 
<p>Claude Opus 4.7 is an&nbsp;upgrade from Claude Opus 4.6, with stronger performance across the workflows teams&nbsp;run&nbsp;in production.&nbsp;Opus 4.7 works better through ambiguity, is more thorough in its problem solving, and&nbsp;folllows&nbsp;instructions more precisely.&nbsp;For coding, the model extends agentic capabilities with improved long-horizon autonomy, systems engineering, and complex code reasoning. For knowledge work, Claude Opus 4.7 advances professional tasks such as&nbsp;slides and&nbsp;document creation, financial analysis, and&nbsp;data visualization. For long-running tasks, the model stays on track&nbsp;over longer horizons with improved reasoning and memory capabilities. Claude Opus 4.7 also advances visual&nbsp;capabilities&nbsp;with high-resolution image support&nbsp;improving accuracy on charts, dense documents, and&nbsp;screen&nbsp;UIs where fine detail matters.&nbsp;&nbsp;</p> 
<p>Claude Opus&nbsp;4.7 is&nbsp;served&nbsp;through&nbsp;Amazon Bedrock's next-generation inference engine, delivering enterprise-grade infrastructure for production workloads.&nbsp;It provides zero operator data access, meaning customer&nbsp;prompts&nbsp;and responses are never visible to Anthropic or AWS operators, keeping sensitive data private. It also enables&nbsp;enhanced&nbsp;availability through&nbsp;dynamic traffic routing with expanded in-region options, along with improved scalability.</p> 
<p>Claude Opus 4.7 is available in select&nbsp;<a href="https://docs.aws.amazon.com/bedrock/latest/userguide/models-region-compatibility.html" rel="noopener noreferrer" target="_blank">AWS Regions</a>.&nbsp;To learn more about Claude Opus 4.7 and other&nbsp;Anthropic&nbsp;models available&nbsp;in&nbsp;Amazon Bedrock, visit the&nbsp;<a href="https://aws.amazon.com/bedrock/anthropic/" rel="noopener noreferrer" target="_blank">Amazon Bedrock&nbsp;page</a>. To get started, see the&nbsp;<a href="https://docs.aws.amazon.com/bedrock/latest/userguide/what-is-bedrock.html" rel="noopener noreferrer" target="_blank">Amazon Bedrock documentation</a>.&nbsp;</p>
