### AWS Managed Microsoft AD is now available on Windows functional level 2016

### AWS Managed Microsoft AD now supports Kerberos Encryption audit event logs

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/04/aws-managed-microsoft-ad-kerberose-encrption-logs/](https://aws.amazon.com/about-aws/whats-new/2026/04/aws-managed-microsoft-ad-kerberose-encrption-logs/)
- **Published**: 2026-04-20 16:00:00
- **Fetched**: 2026-04-21 08:39:09

<p>Starting today, AWS Managed Microsoft AD supports forwarding Kerberos&nbsp;Encryption audit&nbsp;event logs (Event IDs 201–209) to Amazon CloudWatch Logs. These logs provide visibility into the encryption types used by your&nbsp;applications&nbsp;and services, helping you&nbsp;identify&nbsp;which resources are using RC4 encryption versus AES encryption. This visibility allows you to decide whether to upgrade clients to AES encryption (recommended for improved security) or maintain RC4 support based on your environment's compatibility requirements.</p> 
<p>To get started, navigate to your AWS Managed Microsoft AD directory&nbsp;Network and Security tab&nbsp;in the AWS Directory Service console and enable log&nbsp;forwarding&nbsp;to Amazon CloudWatch Logs. You can then review the&nbsp;Kerberos Encryption audit&nbsp;events to understand your current encryption&nbsp;settings.&nbsp;To learn more,&nbsp;see&nbsp;<a href="https://docs.aws.amazon.com/directoryservice/latest/admin-guide/ms_ad_enable_log_forwarding.html">Enabling Amazon CloudWatch Logs log forwarding for AWS Managed Microsoft AD.</a></p> 
<p>This feature is available in all&nbsp;<a href="https://docs.aws.amazon.com/directoryservice/latest/admin-guide/regions.html">AWS Regions</a>&nbsp;where AWS Managed Microsoft AD is available,&nbsp;except in the Middle East (UAE) and Middle East (Bahrain) Regions.</p>

### Amazon MSK Replicator now supports enhanced consumer offset synchronization for bidirectional replication

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/04/amazon-msk-replicator-enhanced-consumer-offset-synchronization/](https://aws.amazon.com/about-aws/whats-new/2026/04/amazon-msk-replicator-enhanced-consumer-offset-synchronization/)
- **Published**: 2026-04-21 00:00:00
- **Fetched**: 2026-04-21 08:39:09

<p>Amazon MSK Replicator now provides enhanced consumer offset synchronization for bidirectional replication, enabling applications to resume processing from the correct position when moving across Kafka clusters. This capability enables you to move producer and consumer applications between clusters independently, in any order, without the risk of data loss. &nbsp;</p> 
<p>MSK Replicator is a feature of Amazon MSK that automates data replication between Kafka clusters,&nbsp;eliminating&nbsp;the need to manage custom replication&nbsp;infrastructure or configure open-source tools. Previously, while replicating bidirectionally with MSK Replicator,&nbsp;consumer group offsets were synchronized only when producers and consumers were active on the same cluster,&nbsp;requiring careful sequencing of application migrations between clusters and increasing the risk of duplicate message processing during rollbacks.&nbsp;With this launch,&nbsp;MSK Replicator synchronizes consumer group offsets across source and target clusters regardless of where producers are running, enabling applications to move between clusters without coordination constraints or data duplication risks.</p> 
<p>You can enable&nbsp;enhanced consumer offset synchronization&nbsp;when creating a Replicator using the Amazon MSK console, AWS CLI, or AWS CloudFormation. This capability is supported in all AWS Regions where MSK Replicator is available.&nbsp;</p> 
<p>To learn more, visit the MSK Replicator&nbsp;<a href="https://docs.aws.amazon.com/msk/latest/developerguide/msk-replicator.html">documentation</a>,&nbsp;<a href="https://aws.amazon.com/msk/features/msk-replicator/">product page</a>,&nbsp;<a href="https://aws.amazon.com/msk/pricing/">pricing page</a>, and this <a href="https://aws.amazon.com/blogs/big-data/migrate-third-party-and-self-managed-apache-kafka-clusters-to-amazon-msk-express-brokers-with-amazon-msk-replicator/">AWS blog post</a>.</p>
