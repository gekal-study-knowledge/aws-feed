### Amazon CloudWatch introduces PromQL querying with Query Studio Preview

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/04/amazon-cloudwatch-query-studio-preview/](https://aws.amazon.com/about-aws/whats-new/2026/04/amazon-cloudwatch-query-studio-preview/)
- **Published**: 2026-04-03 16:00:00
- **Fetched**: 2026-04-03 16:00:00

<div class="entry-summary">
<p>Amazon CloudWatch announces Query Studio in public preview, a unified query and visualization experience that brings native PromQL querying to CloudWatch for the first time. Query Studio combines PromQL and CloudWatch Metric Insights in a single interface, enabling you to query AWS vended metrics and OpenTelemetry metrics using the language you prefer without switching between consoles.<br /> <br /> Query Studio provides a visual form builder with autocomplete and a code editor with syntax highlighting, making it accessible to both new and experienced users. For example, a team running applications on Amazon EC2 can correlate their custom OpenTelemetry application metrics with EC2 vended metrics side by side, quickly spot issues across their stack, and create alarms or add charts to dashboards directly from their query results.<br /> <br /> Amazon CloudWatch Query Studio is available in public preview in US East (N. Virginia), US West (Oregon), Asia Pacific (Sydney), Asia Pacific (Singapore), and Europe (Ireland). Standard CloudWatch dashboard pricing applies, see <a href="https://aws.amazon.com/cloudwatch/pricing/" target="_blank">pricing page</a> for details.<br /> <br /> To get started, open Query Studio from the Metrics console or dashboard edit mode in the <a href="https://console.aws.amazon.com/cloudwatch/">Amazon CloudWatch console</a>. Learn more on the Amazon CloudWatch <a href="https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/CloudWatch-OpenTelemetry-Sections.html" target="_blank">documentation page</a>.</p>
</div>

### Amazon Quick Enables Sparklines for Inline Trend Visualization in Tables

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/04/quick-sparklines-tables/](https://aws.amazon.com/about-aws/whats-new/2026/04/quick-sparklines-tables/)
- **Published**: 2026-04-04 00:00:00
- **Fetched**: 2026-04-04 00:00:00

<div class="entry-summary">
<p><a href="https://aws.amazon.com/quick/quicksight/" rel="noopener noreferrer" target="_blank">Quick Sight in Amazon Quick</a> now supports sparklines, enabling authors to embed compact, inline trend visualizations directly within table cells. Sparklines allow users to display line or area charts inside individual table columns, providing at-a-glance trend context alongside their data without requiring separate chart visuals. Authors can add sparklines to tables by configuring a metric with a date dimension, and Quick automatically renders a miniature trend line within each row.</p> 
<p>This enhancement helps organizations quickly identify patterns, anomalies, and directional trends within tabular data — such as revenue over time by product, weekly ticket volumes by team, or monthly utilization by region — without navigating away from the table view. Sparklines support customization options including visual type (line or area), line color, line interpolation (linear, smooth, or stepped), and Y-axis behavior (shared or independent scaling across rows), giving authors flexibility to tailor the visualization to their dashboard's needs.</p> 
<p>This feature is now available in all Amazon Quick <a href="https://docs.aws.amazon.com/quicksuite/latest/userguide/regions.html" rel="noopener noreferrer" target="_blank">regions where Quick Sight is supported.</a> Learn more about how to <a href="https://docs.aws.amazon.com/quick/latest/userguide/format-sparklines.html" rel="noopener noreferrer" target="_blank">add sparklines to your tables</a> in Amazon Quick.</p>
</div>

### AWS Secrets Manager console now supports custom input for AWS KMS keys

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/04/aws-secrets-manager-console-custom-kms-key-input/](https://aws.amazon.com/about-aws/whats-new/2026/04/aws-secrets-manager-console-custom-kms-key-input/)
- **Published**: 2026-04-04 03:00:00
- **Fetched**: 2026-04-04 03:00:00

<div class="entry-summary">
<p>AWS Secrets Manager console now allows you to specify a custom customer managed AWS Key Management Service (KMS) key when creating secrets. You can now provide a KMS key Amazon Resource Name (ARN) directly in the console, in addition to selecting from the pre-populated list of KMS keys in your current account.</p> 
<p>Previously, when creating a secret through the AWS Secrets Manager console, you could only select customer managed KMS keys from a dropdown list that displayed keys within the same AWS account. With this enhancement, you can now enter a KMS key ARN to use a key from a different account, aligning the console experience with the existing API capabilities. This simplifies cross-account encryption workflows and provides greater flexibility in managing your encryption keys across multiple accounts.</p> 
<p>This feature is available in all AWS Regions where AWS Secrets Manager is available. To learn more about using customer managed KMS keys with AWS Secrets Manager, visit the&nbsp;<a href="https://docs.aws.amazon.com/secretsmanager/">AWS Secrets Manager documentation</a>.</p>

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/04/partner-revenue-measurement-user-agent-support/](https://aws.amazon.com/about-aws/whats-new/2026/04/partner-revenue-measurement-user-agent-support/)

- **Fetched**: 2026-04-04 03:55:00

<details class="entry-summary">
<summary>詳細を表示</summary>
<p>Today, AWS announces the general availability of Partner Revenue Measurement User Agent string — a new capability that enables AWS Partners to measure AWS service consumption driven by their solutions using AWS APIs and SDKs. Partner Revenue Measurement allows Partners to better understand their AWS revenue impact and product consumption patterns. The User Agent string capability allows Partners to embed a unique product code from their AWS Marketplace listing as a user agent to quantify and measure the AWS revenue impact of that solution across certain services. &nbsp;</p> 
<p>Partners can now add a user agent (format APN_1.1/pc_&lt;AWS Marketplace product-code&gt;$) in their application to enable AWS service consumption measurement by solution across partner-managed and customer-managed accounts. <p>Partner Revenue Measurement is generally available in all commercial regions. To learn more about User Agent string implementation, visit the <a href="https://docs.aws.amazon.com/PRM/latest/aws-prm-onboarding-guide/user-agent-string.html">User Agent implementation guide</a> and <a href="https://docs.aws.amazon.com/PRM/latest/aws-prm-onboarding-guide/user-agent-included-services.html">services supported</a>. To learn more about Partner Revenue Measurement capabilities, review the <a href="https://docs.aws.amazon.com/PRM/latest/aws-prm-onboarding-guide/what-is-service.html">onboarding guide</a> for more information.</p>
</details>

<p>Amazon Bedrock Guardrails now enables centralized enforcement of safety controls across all AWS accounts within an organization through cross-account safeguards. Amazon Bedrock Guardrails offers configurable safeguards that help block up to 88% of harmful multimodal content from both input prompts and model responses, while filtering hallucinated responses from foundation models. Central security teams and administrators can now automatically implement these controls for all foundation model interactions in Amazon Bedrock across their organization, eliminating the operational overhead of manually configuring guardrails for each account.<br /> <br /> With cross-account safeguards, you can specify a guardrail ID from your management account in a new <a href="https://docs.aws.amazon.com/organizations/latest/userguide/orgs_manage_policies_bedrock.html" target="_blank">Amazon Bedrock policy</a> that automatically enforces configured safeguards across all member entities including organizational units (OUs) and individual accounts for all model invocations with Amazon Bedrock.&nbsp;This enables operational efficiency through automatic enforcement from a single control point in your management account.
