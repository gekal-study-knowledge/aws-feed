### Amazon Connect Outbound Campaigns now supports contact priority ordering

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/04/amazon-connect-priority-dialing/](https://aws.amazon.com/about-aws/whats-new/2026/04/amazon-connect-priority-dialing/)
- **Published**: 2026-04-21 02:03:00

<p>Amazon Connect&nbsp;Outbound&nbsp;Campaigns now&nbsp;allows&nbsp;you to dial contacts in configurable priority order based on up to 10 profile attributes for voice campaigns and voice activities in journeys.&nbsp;This helps you focus agent time on the most valuable customers or time-sensitive opportunities, improving campaign effectiveness and conversion rates.</p> 
<p>With contact priority ordering, you can sort segments on attributes such as customer lifetime value, account tier, or appointment date. For example, a financial services team can prioritize outreach to high-value accounts nearing contract renewal, or a healthcare provider can ensure patients with the earliest upcoming appointments are contacted first. Initial dial attempts always take precedence over reattempts, ensuring your priority order is&nbsp;maintained&nbsp;throughout campaign execution.&nbsp;</p> 
<p>This capability is available in all AWS Regions where Amazon Connect&nbsp;Outbound&nbsp;Campaigns&nbsp;is&nbsp;offered at no&nbsp;additional&nbsp;cost. To get started, configure sort attributes when building segments in Amazon Connect Customer Profiles. To learn more, see the Amazon Connect&nbsp;<a href="https://docs.aws.amazon.com/connect/latest/adminguide/outbound-campaign-best-practices.html">Outbound&nbsp;Campaigns&nbsp;best practice</a>&nbsp;and&nbsp;<a href="https://docs.aws.amazon.com/connect/latest/adminguide/customer-segments-building-segments.html">how to build customer segments</a>.&nbsp;</p>

### AWS Lambda Durable Execution SDK for Java GA

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/04/lambda-durable-execution-java-ga/](https://aws.amazon.com/about-aws/whats-new/2026/04/lambda-durable-execution-java-ga/)
- **Published**: 2026-04-21 06:00:00

<p>Today, AWS announces the general availability of the AWS Lambda Durable Execution SDK for Java, empowering Java developers to build resilient, long-running workflows using Lambda durable functions. With this SDK, developers can create multi-step applications like order processing pipelines, AI agent orchestration, and human-in-the-loop approvals directly in their applications without implementing custom progress tracking or integrating external orchestration services.</p> 
<p>Lambda durable functions extend Lambda's event-driven programming model with operations that checkpoint progress automatically and pause execution for up to a year when waiting on external events. The AWS Lambda Durable Execution SDK for Java provides an idiomatic Java experience for building with Lambda durable functions. It includes steps for progress tracking, callback integration for human and agent-in-the-loop workflows, durable invocation for reliable function chaining, and waits for efficient suspension. The SDK is compatible with Java 17+ and can be deployed using Lambda managed runtimes or functions packaged as container images. The local testing emulator in the SDK enables developers to build and debug locally before deploying to production.</p> 
<p>To get started, see the <a href="https://docs.aws.amazon.com/lambda/latest/dg/durable-functions.html" rel="noopener noreferrer" target="_blank">Lambda durable functions developer guide</a> and the <a href="https://github.com/aws/aws-durable-execution-sdk-java/" rel="noopener noreferrer" target="_blank">AWS Lambda Durable Execution SDK for Java on GitHub</a>. For Regional availability and pricing details, see the <a href="https://builder.aws.com/build/capabilities" rel="noopener noreferrer" target="_blank">AWS Regional Services List</a> and <a href="https://aws.amazon.com/lambda/pricing/" rel="noopener noreferrer" target="_blank">AWS Lambda Pricing</a>.</p>

### AWS Lambda functions can now mount Amazon S3 buckets as file systems with S3 Files

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/04/aws-lambda-amazon-s3/](https://aws.amazon.com/about-aws/whats-new/2026/04/aws-lambda-amazon-s3/)
- **Published**: 2026-04-21 17:00:00

<p>AWS Lambda now supports&nbsp;<a href="https://aws.amazon.com/s3/features/files/" target="_blank">Amazon S3 Files</a>, enabling your Lambda functions to mount Amazon S3 buckets as file systems and perform standard file operations without downloading data for processing. Built using Amazon EFS, S3 Files gives you the performance and simplicity of a file system with the scalability, durability, and cost-effectiveness of S3. Multiple Lambda functions can connect to the same S3 Files file system simultaneously, sharing data through a common workspace&nbsp;without&nbsp;building custom synchronization logic.</p> 
<p><a href="https://docs.aws.amazon.com/lambda/latest/dg/durable-functions.html"></a>The&nbsp;S3 Files integration simplifies stateful workloads in Lambda by&nbsp;eliminating&nbsp;the overhead of downloading objects, uploading results, and managing ephemeral storage limits.&nbsp;This is particularly valuable for AI and machine learning workloads where agents need to&nbsp;persist&nbsp;memory and share state across pipeline steps.&nbsp;<a href="https://docs.aws.amazon.com/lambda/latest/dg/durable-functions.html" target="_blank">Lambda durable functions</a>&nbsp;make&nbsp;these multi-step AI workflows possible by orchestrating parallel execution with automatic checkpointing. For example, an orchestrator function can clone a repository to a shared workspace while multiple agent functions analyze the code in parallel. The durable function handles checkpointing of execution state while S3 Files provides seamless data sharing across all steps.</p> 
<p>To use S3 Files with Lambda, configure your function to mount an S3 bucket through the Lambda console, AWS CLI, AWS SDKs,&nbsp;AWS CloudFormation, or&nbsp;AWS Serverless Application Model (SAM).&nbsp;To learn more about how to use S3 Files with your Lambda function, visit the&nbsp;<a href="https://docs.aws.amazon.com/lambda/latest/dg/configuration-filesystem-s3files.html">Lambda developer guide</a>.&nbsp;</p> 
<p><a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/"></a>S3 Files is supported for Lambda functions not configured with a capacity provider, in all&nbsp;<a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">AWS Regions</a>&nbsp;where both Lambda and&nbsp;S3 Files are available, at no&nbsp;additional&nbsp;charge beyond standard Lambda and S3 pricing.</p>
