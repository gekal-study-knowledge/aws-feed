## AWS What's New

### AWS Private CA now publishes utilization metrics to Amazon CloudWatch

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/03/aws-private-ca-publishes-metrics/](https://aws.amazon.com/about-aws/whats-new/2026/03/aws-private-ca-publishes-metrics/)
- **Published**: 2026-03-31 13:00:00

<p>AWS Private Certificate Authority (AWS Private CA) now publishes certificate authority (CA) utilization metrics to Amazon CloudWatch, providing visibility into your CA usage. AWS Private CA enforces service quota limits on the number of certificates a CA can issue and the number of CAs you can create per Region. The new metrics track the number of certificates issued by each CA and the total number of CAs in each Region, enabling you to monitor usage against these quotas and proactively manage CA lifecycle to maintain high availability.<br /> <br /> With these metrics, you can configure CloudWatch alarms to prevent quota-related service disruptions. For example, you can set alarms to trigger automation that replaces a CA approaching its certificate issuance quota and transitions certificate issuance to a new CA. This is particularly important when using AWS services that rely on AWS Private CA certificates, such as Amazon EKS, Amazon ECS Service Connect, and Amazon WorkSpaces.</p> 
<p>The utilization metrics are available in all AWS Regions where AWS Private CA is available.&nbsp;To learn more about AWS Private CA metrics, see the&nbsp;<a href="https://docs.aws.amazon.com/privateca/latest/userguide/PcaCloudWatch.html">AWS Private CA User Guide</a>.&nbsp;<br /> </p>

### AWS Security Agent on-demand penetration testing is now generally available

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/03/aws-security-agent-ondemand-penetration/](https://aws.amazon.com/about-aws/whats-new/2026/03/aws-security-agent-ondemand-penetration/)
- **Published**: 2026-03-31 14:00:00

<p>Today,&nbsp;AWS&nbsp;announced the general availability of AWS&nbsp;Security&nbsp;Agent&nbsp;for&nbsp;on-demand penetration testing&nbsp;in&nbsp;six&nbsp;AWS Regions.&nbsp;AWS Security Agent&nbsp;delivers&nbsp;autonomous penetration testing that&nbsp;operates&nbsp;24/7 at a&nbsp;fraction of the cost&nbsp;than manual penetration&nbsp;tests. This milestone transforms penetration testing from a periodic bottleneck into an on-demand capability that scales with your development velocity&nbsp;across AWS, Azure, GCP, other&nbsp;cloud-providers, and on-premises. With&nbsp;multicloud&nbsp;support, AWS Security Agent allows you to&nbsp;consolidate&nbsp;penetration testing across your entire infrastructure.&nbsp;</p> 
<p><a href="https://aws.amazon.com/blogs/aws/new-aws-security-agent-secures-applications-proactively-from-design-to-deployment-preview/">Previewed</a>&nbsp;at&nbsp;re:Invent&nbsp;2025,&nbsp;AWS Security Agent&nbsp;represents&nbsp;a new class of frontier agents&nbsp;that are&nbsp;autonomous systems that work independently to achieve goals, scale to tackle concurrent tasks, and run persistently without constant human oversight. It deploys specialized AI agents to help discover,&nbsp;validate, and report security vulnerabilities through sophisticated multi-step attack scenarios&nbsp;customized for each application.&nbsp;It&nbsp;provides detailed findings with CVSS risk scores, application-specific severity ratings,&nbsp;reproduction steps, and remediation suggestions.&nbsp;</p> 
<p>AWS Security Agent&nbsp;is now available in&nbsp;US&nbsp;East (N. Virginia), US West (Oregon), Europe (Ireland), Europe (Frankfurt), Asia Pacific (Sydney), and Asia Pacific (Tokyo) regions.&nbsp;</p> 
<p>New customers can explore&nbsp;AWS Security Agent&nbsp;with a&nbsp;2-month&nbsp;free trial. For pricing and feature details, visit the&nbsp;<a href="https://aws.amazon.com/security-agent/pricing/">AWS Security Agent pricing page</a>.&nbsp;To learn more about AWS Security Agent, visit the&nbsp;<a href="https://aws.amazon.com/security-agent?refid=04d587d8-77d6-4750-bffa-2bc5a475e1a9">product page</a>&nbsp;and read the&nbsp;<a href="https://aws.amazon.com/blogs/security/aws-security-agent-on-demand-penetration-testing-now-generally-available/">launch announcement</a>.&nbsp;For technical details and to get started, see the&nbsp;<a href="https://docs.aws.amazon.com/securityagent/latest/userguide/what-is.html?refid=04d587d8-77d6-4750-bffa-2bc5a475e1a9">AWS Security Agent documentation</a>.&nbsp;</p>
