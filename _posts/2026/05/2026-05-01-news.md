# AWS Updates - 2026-05-01

## AWS What's New

### Amazon MQ for RabbitMQ now supports Prometheus metrics

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/04/amazon-mq-rabbitmq-prometheus-metrics/](https://aws.amazon.com/about-aws/whats-new/2026/04/amazon-mq-rabbitmq-prometheus-metrics/)
- **Published**: 2026-05-01 03:10:00
- **Fetched**: 2026-05-01 04:15:04

<p><a href="https://aws.amazon.com/amazon-mq/" rel="noopener noreferrer" target="_blank">Amazon MQ</a> for RabbitMQ now supports the Prometheus plugin on RabbitMQ 4.2 brokers, providing a native Prometheus-compatible metrics endpoint on your RabbitMQ brokers. You can scrape broker, queue, and connection metrics directly from your brokers using any Prometheus-compatible monitoring tool, giving you more flexibility in how you observe and alert on your messaging infrastructure.<br /> <br /> The plugin exposes metrics through the /metrics, /metrics/detailed, and /metrics/memory-breakdown endpoints in Prometheus text format. Amazon MQ also publishes a curated subset of these Prometheus metrics to CloudWatch. With the Prometheus plugin, you can now integrate your brokers into existing Prometheus-based monitoring stacks including Grafana dashboards, Amazon Managed Service for Prometheus, and self-hosted Prometheus servers.<br /> <br /> The Prometheus plugin is enabled by default on all Amazon MQ for RabbitMQ 4.2 brokers in all <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/" rel="noopener noreferrer" target="_blank">AWS Regions</a> where Amazon MQ is available. To learn more about monitoring with Prometheus, see the <a href="https://docs.aws.amazon.com/amazon-mq/latest/developer-guide/amazon-mq-release-notes.html" rel="noopener noreferrer" target="_blank">Amazon MQ release notes</a>.</p>
