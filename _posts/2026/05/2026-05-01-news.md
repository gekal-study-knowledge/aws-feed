Once approved, the new root certificate becomes active and available for use within the service. <p>Amazon Bedrock AgentCore Identity now supports On-Behalf-Of (OBO) token exchange, enabling developers to build agents that securely access protected resources on behalf of authenticated users — without requiring users to complete multiple consent flows.<br /> <br /> Previously, developers building agents that needed to act on behalf of a user had to manage separate consent flows for each protected resource, adding friction for end users and complexity for builders. ### AWS Payment Cryptography now supports paper-based key exchange

- **Fetched**: 2026-05-02 02:56:50

<p><a href="https://aws.amazon.com/payment-cryptography/">AWS Payment Cryptography</a> now supports Physical Key Exchange, a new PCI PIN and P2PE compliant feature for performing paper-based cryptographic key exchange with the service without needing to maintain your own secure key loading infrastructure. If your partners or vendors do not support electronic key exchange,&nbsp;Physical Key Exchange provides an option to exchange cryptographic keys to accelerate your migration. AWS Payment Cryptography is a managed service that provides elastic key management and cryptographic operations for your cloud-hosted payment applications.</p> 
<p>Although electronic key exchange is preferred, some counter parties are not yet ready to support it, requiring organizations to maintain Hardware Security Modules (HSMs) and Key Loading Devices (KLDs) to perform paper-based key ceremonies in a compliant manner. Maintaining this infrastructure is costly and operationally burdensome, especially for key exchanges that occur only a few times per year. With Physical Key Exchange,&nbsp;paper key components are shipped to trained&nbsp;AWS key custodians, who handle them securely and perform key ceremonies in AWS-operated secure facilities that meet the PCI PIN and P2PE physical and logical security requirements. Once loaded into AWS Payment Cryptography, keys are available to perform cryptographic operations.&nbsp;</p> 
<p>For details on key exchange options in AWS Payment Cryptography, see the <a href="https://docs.aws.amazon.com/payment-cryptography/latest/userguide/keys-physicalkeyexchange.html">Physical Key Exchange</a> for paper-based and <a href="https://docs.aws.amazon.com/payment-cryptography/latest/userguide/keys-importexport.html">importing and exporting keys</a> for electronic key exchange in the User Guide. For pricing details, visit the <a href="https://aws.amazon.com/payment-cryptography/pricing/">pricing page</a>. To get started, open an <a href="https://console.aws.amazon.com/support/">AWS support case</a> or contact your AWS account team.</p>
