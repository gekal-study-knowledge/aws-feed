# AWS Updates - 2026-05-14

## AWS What's New

### Amazon FSx for OpenZFS now supports creating Multi-AZ file systems in shared VPCs

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/05/amazon-fsx-openzfs-multi-az-vpcs/](https://aws.amazon.com/about-aws/whats-new/2026/05/amazon-fsx-openzfs-multi-az-vpcs/)
- **Published**: 2026-05-14 04:00:00
- **Fetched**: 2026-05-14 07:06:54

<p>Amazon&nbsp;FSx&nbsp;for&nbsp;OpenZFS&nbsp;now&nbsp;allows&nbsp;you to create&nbsp;Multi-AZ&nbsp;file systems in&nbsp;shared&nbsp;VPCs&nbsp;within your AWS organization, making it easier for you&nbsp;to decentralize&nbsp;network and storage&nbsp;administration.</p> 
<p><a href="https://docs.aws.amazon.com/vpc/latest/userguide/vpc-sharing.html">VPC&nbsp;sharing</a>&nbsp;is&nbsp;a feature that allows resource owners ("owner accounts") to share one or more VPC subnets with other accounts ("participant accounts") in their AWS organization. Participant accounts can then&nbsp;view, create,&nbsp;modify, delete, and&nbsp;manage their&nbsp;application resources in the subnets&nbsp;shared&nbsp;with them. Previously, participant accounts could create Single-AZ&nbsp;OpenZFS&nbsp;file systems in&nbsp;VPCs&nbsp;shared&nbsp;with&nbsp;them, but&nbsp;could only create&nbsp;Multi-AZ&nbsp;file&nbsp;systems in VPCs they owned.&nbsp;Starting today, participant accounts can create any&nbsp;FSx&nbsp;for&nbsp;OpenZFS&nbsp;file system in a&nbsp;shared&nbsp;VPC, allowing&nbsp;organizations&nbsp;to run&nbsp;highly available&nbsp;file systems with centralized network management.</p> 
<p>You can create Multi-AZ&nbsp;FSx&nbsp;for&nbsp;OpenZFS&nbsp;file systems from shared VPC participant accounts in&nbsp;<a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/?refid=bc0b1108-3dde-4bd6-8c6b-5bc65141884a">all AWS Regions where Amazon&nbsp;FSx&nbsp;for&nbsp;OpenZFS&nbsp;is available</a>. To learn more, visit the&nbsp;FSx&nbsp;for&nbsp;<a href="https://docs.aws.amazon.com/fsx/latest/OpenZFSGuide/what-is-fsx.html">OpenZFS&nbsp;documentation</a>&nbsp;and the&nbsp;<a href="https://aws.amazon.com/fsx/openzfs/">FSx&nbsp;for&nbsp;OpenZFS&nbsp;product page</a>.</p>
