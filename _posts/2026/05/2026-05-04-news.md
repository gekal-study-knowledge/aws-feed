# AWS Updates - 2026-05-04

## AWS What's New

### Amazon RDS for SQL Server now supports M8i and R8i instances

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/05/rds-sqlserver-supports-m8i-r8i-instances/](https://aws.amazon.com/about-aws/whats-new/2026/05/rds-sqlserver-supports-m8i-r8i-instances/)
- **Published**: 2026-05-04 16:00:00
- **Fetched**: 2026-05-05 06:04:55

<p><a href="https://aws.amazon.com/rds/sqlserver/">Amazon Relational Database Service (Amazon RDS) for SQL Server</a> now supports M8i and R8i instances. These instances are powered by custom Intel Xeon 6 processors, available only on AWS, delivering the highest performance and fastest memory bandwidth among comparable Intel processors in the cloud. The M8i and R8i instances offer up to 15% better price-performance and 2.5x more memory bandwidth compared to equivalent 7th generation Intel-based instances.<br /> <br /> To use the new M8i and R8i instances, you can modify your existing RDS database instance or create a new RDS database instance from the RDS Management Console, or using the AWS SDK or CLI.<br /> <br /> See <a href="https://aws.amazon.com/rds/sqlserver/pricing/">Amazon RDS for SQL Server Pricing</a> for up-to-date pricing and regional availability.</p>

### AWS Payment Cryptography announces support for cross account key sharing

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/05/payment-cryptography-resource/](https://aws.amazon.com/about-aws/whats-new/2026/05/payment-cryptography-resource/)
- **Published**: 2026-05-04 23:58:00
- **Fetched**: 2026-05-05 04:23:49

<p><a href="https://aws.amazon.com/payment-cryptography/">AWS Payment Cryptography</a>&nbsp;now supports cross account sharing of keys using resource-based policies (RBP).&nbsp; With this new feature, customers can more easily manage cryptographic keys across multiple accounts both internal and external to their company, providing more flexibility to manage keys at scale.&nbsp; With AWS Payment Cryptography, you can simplify cryptography operations in your cloud-hosted payment applications with a service that grows elastically with your business and has been assessed as compliant with PCI PIN Security and Point-to-Point Encryption (P2PE) requirements.</p> 
<p>Many customers utilize multiple AWS accounts to delineate different workloads, applications or use cases for payment processing following <a href="https://aws.amazon.com/blogs/security/pci-dss-v4-0-on-aws-compliance-guide-now-available/" rel="noopener noreferrer" target="_blank">AWS PCI DSS Guidance</a>.&nbsp; While this pattern is also common with traditional infrastructure, this often leads to duplicating cryptographic material, making lineage and access controls more difficult overall.&nbsp; With the launch of Payment Cryptography integration with RBP, customers can keep a single copy of key material and leverage concise, per-resource access control to enable cross account access without relying on import/export flows.</p> 
<p>This feature is available across all&nbsp;<a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">AWS Regions</a>&nbsp;where AWS Payment Cryptography is available.&nbsp; To learn more about this feature or to get started with the service, consult the AWS Payment Cryptography <a href="https://docs.aws.amazon.com/payment-cryptography/latest/userguide/security_iam_resource-based-policies.html" rel="noopener noreferrer" target="_blank">user guide</a>.</p>
