# AWS Updates - 2026-06-10

## AWS What's New

### AWS FinOps Agent is now available in preview

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/06/aws-finops-agent-preview/](https://aws.amazon.com/about-aws/whats-new/2026/06/aws-finops-agent-preview/)
- **Published**: 2026-06-10 00:28:00
- **Fetched**: 2026-06-10 02:59:06

<p>Today, AWS announces the preview of AWS FinOps Agent, a frontier agent for FinOps practitioners and engineering teams that answers cost questions, surfaces optimization opportunities, automatically investigates cost anomalies, and runs recurring FinOps workflows on a schedule you define.</p> 
<p>With&nbsp;the&nbsp;AWS FinOps Agent, you can ask&nbsp;questions&nbsp;about your AWS costs&nbsp;and generate cloud cost reports for finance and engineering teams. The agent surfaces rightsizing, idle resource, and Savings Plans recommendations from AWS Cost Optimization Hub and AWS Compute&nbsp;Optimizer, and&nbsp;can open Jira tickets on your behalf. When a cost anomaly is detected, FinOps Agent can automatically investigate the root cause and&nbsp;can&nbsp;post the findings to a Slack channel, so engineering teams are notified without manual triage.</p> 
<p>AWS FinOps Agent&nbsp;(preview)&nbsp;is available in the US East (N. Virginia) Region and includes cost and usage data covering all AWS Regions, except AWS GovCloud (US) Regions and AWS China (Beijing and Ningxia) Regions. AWS FinOps Agent is offered at no&nbsp;additional&nbsp;charge during the preview.</p> 
<p>Learn more about AWS FinOps Agent in the&nbsp;<a href="https://docs.aws.amazon.com/finops-agent/latest/userguide/what-is.html">User Guide</a>,&nbsp;<a href="http://aws.amazon.com/finops-agent">product details page</a>, and the&nbsp;<a href="https://aws.amazon.com/blogs/aws-cloud-financial-management/aws-finops-agent-is-now-public-preview">blog</a>. Get started by visiting the AWS FinOps Agent page in the AWS Management Console.</p>
