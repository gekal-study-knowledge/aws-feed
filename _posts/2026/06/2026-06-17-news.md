# AWS Updates - 2026-06-17

## AWS What's New

### AWS Sign-in now supports resource-based policies and resource control policies

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/06/aws-sign-in/](https://aws.amazon.com/about-aws/whats-new/2026/06/aws-sign-in/)
- **Published**: 2026-06-17 01:20:00
- **Fetched**: 2026-06-17 03:02:26

<p>AWS Sign-in now supports resource-based policies and resource control policies (RCPs) for the AWS Management Console. You can use these policies to restrict console sign-in to expected networks. Policies are evaluated during sign-in and whenever the console session requests new credentials.</p> 
<p>Resource-based policies apply to individual AWS accounts. Resource control policies apply organization-wide through AWS Organizations. You can combine these policies with <a href="https://docs.aws.amazon.com/awsconsolehelpdocs/latest/gsg/console-private-access.html" target="_blank">AWS Management Console Private Access</a> to control both which networks users can sign in from and which accounts they can access.</p> 
<p>AWS Sign-in resource-based policies and RCPs are available at no additional cost in all AWS commercial Regions. To learn more, see the <a href="https://docs.aws.amazon.com/signin/latest/userguide/what-is-sign-in.html" target="_blank">AWS Sign-in User Guide</a>. For API details, see the <a href="https://docs.aws.amazon.com/signin/latest/APIReference/" target="_blank">AWS Sign-in API Reference</a>.</p>
