## AWS What's New

### Amazon ElastiCache for Valkey now supports durability

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/06/durability-amazon-elasticache](https://aws.amazon.com/about-aws/whats-new/2026/06/durability-amazon-elasticache)
- **Published**: 2026-06-03 00:00:00
- **Fetched**: 2026-06-03 02:18:46

<p>Today, AWS announces durability support for Amazon ElastiCache. Durability enables you to use ElastiCache for workloads that require microsecond read latency but cannot tolerate data loss. With durability support, ElastiCache now stores data durably across multiple Availability Zones (AZs) using a Multi-AZ transactional log to enable fast failover, database recovery, and node restarts to prevent data loss in the unlikely event of a failure.</p> 
<p>You can choose between two durability options: synchronous and asynchronous writes. Synchronous writes persist data across at least two AZs before responding to the client, designed for zero data loss at single-digit millisecond write latency. Asynchronous writes persist data after responding to the client, maintaining microsecond write latency at no additional cost. However, up to 10 seconds of uncommitted data could be lost in the rare event of a failure. Both options maintain microsecond read latency. You can now use ElastiCache for a broader set of use cases beyond caching where data loss is unacceptable such as AI agent long-term memory, AI agent workflow state, knowledge bases for RAG applications, payment tokenization, and real-time inventory management.</p> 
<p>Durability for ElastiCache is available in all AWS commercial Regions, AWS China Regions, and AWS GovCloud (US) Regions starting with Valkey 9.0. To get started, create a new ElastiCache cluster and select your preferred durability option using the AWS Management Console, AWS Software Development Kit (SDK), or AWS Command Line Interface (CLI). For pricing details, visit the <a href="https://aws.amazon.com/elasticache/pricing/">Amazon ElastiCache pricing page</a>. To learn more, visit the <a href="https://docs.aws.amazon.com/AmazonElastiCache/latest/dg/durability.html">ElastiCache documentation</a> and <a href="https://aws.amazon.com/blogs/database/announcing-durability-for-amazon-elasticache/">blog</a>.&nbsp;&nbsp;</p>

### AWS Deadline Cloud now supports persistent storage for Service Managed Fleets

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/06/deadline-cloud/persistent-storage](https://aws.amazon.com/about-aws/whats-new/2026/06/deadline-cloud/persistent-storage)
- **Published**: 2026-06-03 02:00:00
- **Fetched**: 2026-06-03 05:43:25

<p>AWS Deadline Cloud now supports persistent storage for Service-Managed Fleets (SMF), allowing you to maintain data across worker lifecycle events.&nbsp;AWS Deadline Cloud is a fully managed service that makes it easy for teams to run compute-intensive workloads in the cloud for visual effects, animation, product design, simulation, and gaming.<br /> <br /> Previously, Deadline Cloud SMF workers relied only on ephemeral storage, requiring software and assets to be reinstalled each time a worker was recycled or replaced. Now, Deadline Cloud attaches persistent Amazon Elastic Block Store (Amazon EBS) volumes to SMF workers, preserving Conda environments, Perforce workspaces, shader caches, and asset collections across worker lifecycle events. This reduces worker startup time and helps you complete jobs faster.&nbsp;You can configure the number of persistent volumes per worker and set a time-to-live (TTL) to control how long volumes are retained, giving you flexibility to balance storage costs with startup performance.&nbsp;<br /> <br /> Persistent storage for SMF is available in all AWS Regions where Deadline Cloud is offered. Persistent volumes are priced the same as existing Service-Managed Fleets EBS pricing. See the <a href="https://aws.amazon.com/deadline-cloud/pricing/">Deadline Cloud pricing page</a>&nbsp;for details. To learn more, visit the <a href="https://aws.amazon.com/deadline-cloud/">AWS Deadline Cloud product page</a> or our <a href="https://docs.aws.amazon.com/deadline-cloud/latest/userguide/volumes.html">user guide</a>.</p>
