## AWS Security Bulletins

### CVE-2026-19311- Missing Authorization in OpenSearch Alerting Plugin

- **Link**: [https://aws.amazon.com/security/security-bulletins/rss/2026-078-aws/](https://aws.amazon.com/security/security-bulletins/rss/2026-078-aws/)
- **Published**: 2026-08-13 03:46:36
- **Fetched**: 2026-08-13 03:56:20

<p><b>Bulletin ID:</b> 2026-078-AWS<br /> <b>Scope:</b> AWS<br /> <b>Content Type:</b> Important (requires attention)<br /> <b>Publication Date:</b> 08/12/2026 11:30 AM PDT</p> 
<p><b>Description:</b></p> 
<p>OpenSearch is a community-driven, open-source search and analytics suite. We identified CVE-2026-19311, a missing authorization issue in the Execute Monitor API of the OpenSearch Alerting plugin. This issue may allow an authenticated user with the alerting_full_access role to read, modify, or delete arbitrary index data via a crafted inline monitor request with unintentional data source and input index parameters.</p> 
<p><b>Impacted Versions:</b></p> 
<p><b>OpenSearch Alerting Plugin (open-source, self-managed):</b><br /> - <b>Affected:</b> 2.4.0 through 2.19.5, 3.0.0 through 3.7.0<br /> - <b>Fixed:</b> 2.19.6, 3.8.0</p> 
<p><b>Amazon OpenSearch Service (AWS Managed):</b><br /> - <b>Affected:</b> All domains running engine versions 2.4 through 3.5<br /> - <b>Fixed:</b> Service software R20260428-P3</p> 
<p><b>Please refer to the article below for the most up-to-date and complete information related to this AWS Security Bulletin.</b></p>
