### Amazon Quick now supports customizable no data messages for visuals

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2025/08/amazon-quick-custom-no-data-message/](https://aws.amazon.com/about-aws/whats-new/2025/08/amazon-quick-custom-no-data-message/)
- **Published**: 2026-08-15 00:00:00
- **Fetched**: 2026-08-18 07:19:25

<p>Amazon Quick announces support for no data message customization, enabling authors to replace the default "No data to display" message with a tailored message when a visual returns no data. Authors can configure a custom title, subtitle, and hyperlink that give readers immediate context about why no data is shown and what steps to take next.</p> 
<p>All text fields support parameters, so the message can dynamically reflect the reader's current filter selections. The hyperlink supports http://, https://, and mailto: URL schemas, and both the title and subtitle can be toggled on or off independently.</p> 
<p>This feature is available now in all <a href="https://docs.aws.amazon.com/quick/latest/userguide/regions.html" rel="noopener noreferrer" target="_blank">AWS Regions where Amazon Quick is offered</a>. To learn more, visit <a href="https://docs.aws.amazon.com/quick/latest/userguide/analysis-settings.html" rel="noopener noreferrer" target="_blank">Analysis Settings</a> in the Amazon Quick User Guide.</p>

### Amazon Quick adds deny by default for custom permissions

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-quick-deny-by-default-permissions/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-quick-deny-by-default-permissions/)
- **Published**: 2026-08-15 05:57:00
- **Fetched**: 2026-08-18 00:20:23

<p>Amazon Quick custom permissions now include deny by default, a governance setting that automatically restricts new AI capabilities before they reach users.<br /> <br /> Previously, new AI capabilities were available to all users on release, requiring administrators to react after the fact. With deny by default, administrators restrict the AI capability category in a custom permissions profile and assign it to users, roles, or the entire account. Quick then denies any new AI capability at launch for those users. Restricting a category also restricts existing capabilities in it. Administrators explicitly allow each capability when ready. The restriction applies only to the profile you configure.<br /> <br /> Configure deny by default in Manage account in Amazon Quick or through the AWS CLI. To learn more, see <a href="https://docs.aws.amazon.com/quick/latest/userguide/custom-permissions-governance.html">Custom permissions deny by default</a>. Deny by default is available in all AWS Regions where <a href="https://docs.aws.amazon.com/quick/latest/userguide/regions.html">Amazon Quick is available</a>.</p>

### Amazon Quick now supports approval policies for sharing

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-quick-approval-policies-sharing/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-quick-approval-policies-sharing/)
- **Published**: 2026-08-15 06:00:00
- **Fetched**: 2026-08-18 00:20:23

<p>Amazon Quick now offers approval policies, giving administrators governance controls over how assets are shared within their organization. With approval policies, administrators can require designated approvers to review and approve share requests before access is granted, helping organizations ensure that sharing of sensitive assets is deliberate, compliant, and auditable.</p> 
<p>Administrators can create approval policies scoped to specific asset types, including knowledge bases, spaces, and custom chat agents. When a user submits a share request for an asset covered by a policy, it is routed to the assigned approver group for review. Approvers can evaluate the asset directly before approving or denying the request, and all workflow events are captured in AWS CloudTrail for full auditability. For custom chat agents, approvers can review and act on the entire dependency package in a single request.</p> 
<p>This feature is available for Professional and Enterprise plans, in all AWS Regions where Amazon Quick agentic capabilities are supported. For more information, see the <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">AWS Region table</a>.</p> 
<p>Learn more about Amazon Quick by visiting the <a href="https://aws.amazon.com/quick">Quick website</a>. To learn more about approval policies, see Approval policies in the <a href="https://docs.aws.amazon.com/quick/latest/userguide/data-loss-prevention.html">Amazon Quick User Guide</a>.&nbsp;</p>

### Amazon Quick now supports data loss prevention with Microsoft Purview

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-quick-dlp-purview/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-quick-dlp-purview/)
- **Published**: 2026-08-15 06:04:00
- **Fetched**: 2026-08-18 00:20:23

<p>Amazon Quick now integrates with Microsoft Purview to enforce data loss prevention (DLP) policies across your Quick environment. Organizations need to ensure that sensitive files aren't shared outside approved channels. With this integration, IT administrators and security teams can apply their existing Purview sensitivity labels to automatically control how files are handled in Quick capabilities such as chat, spaces, and knowledge bases.</p> 
<p>Administrators can configure enforcement actions (block, warn, or allow) for each sensitivity label, giving organizations granular control over sensitive file sharing across Quick. For example, a financial services company can block files labeled "Highly Confidential" from being uploaded to shared spaces while allowing "Internal" files with a warning notification. With this integration, customers can extend their existing Microsoft Purview governance policies into Quick without additional tools.</p> 
<p>This feature is available in <a href="https://docs.aws.amazon.com/quick/latest/userguide/regions.html">all AWS Regions where Amazon Quick agentic capabilities are supported</a>. For more information, see the <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">AWS Region table</a>. To learn more, see <a href="https://docs.aws.amazon.com/quick/latest/userguide/data-loss-prevention.html">Data loss prevention</a> in the <i>Amazon Quick User Guide</i>.&nbsp;</p>

### Amazon Quick now supports per-user resource limits

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-quick-per-user-resource-limits/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-quick-per-user-resource-limits/)
- **Published**: 2026-08-15 06:07:00
- **Fetched**: 2026-08-18 00:20:23

<p>Amazon Quick now enables administrators to set per-user limits on index storage and agent hours, giving them direct control over subscription costs. With limits management, administrators can create limit profiles that cap per-user consumption, helping prevent unexpected overage charges and ensuring subscription entitlements are used efficiently across their organization.</p> 
<p>For example, an organization deploying Quick enterprise-wide to thousands of users can set account-level limit profiles to establish cost-predictable baselines, then assign higher limits to specific roles that require more agent hours. Administrators can create and assign limit profiles at the user, role, or account level, with a priority hierarchy that ensures the right users get the right capacity. When a user reaches their limit, new consumption is blocked while existing content is preserved.</p> 
<p>This feature is available for Professional and Enterprise plans, in all AWS Regions where Amazon Quick agentic capabilities are supported. For more information, see the <a href="https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/">AWS Region table</a>.</p> 
<p>Learn more about Amazon Quick by visiting the <a href="https://aws.amazon.com/quick">Quick website</a>. To learn more about limit profiles, see Limits management in the <a href="https://docs.aws.amazon.com/quick/latest/userguide/limit-profiles.html">Amazon Quick User Guide</a>.&nbsp;</p>
