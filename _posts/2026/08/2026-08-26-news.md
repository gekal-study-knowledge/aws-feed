# AWS Updates - 2026-08-26

## AWS What's New

### Amazon Connect Customer now lets you update the customer profile on a case or add a profile after a case is opened

- **Link**: [https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-connect-cases-flexible-profiles/](https://aws.amazon.com/about-aws/whats-new/2026/08/amazon-connect-cases-flexible-profiles/)
- **Published**: 2026-08-26 01:00:00
- **Fetched**: 2026-08-26 02:27:20

<p><span style="font-weight: normal;">Amazon Connect Customer now lets agents change the profile on a case or choose a profile after the case is opened. If a case is linked to the wrong customer, agents can update the profile to keep case histories accurate. Agents can also add a profile later when the customer is not identified at case creation, such as for calls from a shared phone number or issues that require identity verification.</span></p> 
<p><span style="font-weight: normal;">Amazon Connect Cases is available in the following AWS regions: US East (N. Virginia), US West (Oregon), Canada (Central), Europe (Frankfurt), Europe (London), Asia Pacific (Seoul), Asia Pacific (Singapore), Asia Pacific (Sydney), Asia Pacific (Tokyo), and Africa (Cape Town). To learn more and get started, visit the Amazon Connect Cases <a href="https://aws.amazon.com/products/connect/customer/cases/">webpage</a> and <a href="https://docs.aws.amazon.com/connect/latest/adminguide/cases.html">documentation</a>.</span></p>
