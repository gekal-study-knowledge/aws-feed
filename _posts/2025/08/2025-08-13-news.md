# AWS Updates - 2025-08-13

## AWS Security Bulletins

### CVE-2025-8904 - Issue with Amazon EMR Secret Agent component

- **Link**: [https://aws.amazon.com/security/security-bulletins/rss/aws-2025-017/](https://aws.amazon.com/security/security-bulletins/rss/aws-2025-017/)
- **Published**: 2025-08-13 00:00:00

<p><b>Bulletin ID:</b> AWS-2025-017<br /> <b>Scope:</b> AWS<br /> <b>Content Type:</b> Important (requires attention)<br /> <b>Publication Date:</b>&nbsp;2025/08/13 10:00 PM PDT</p> 
<p><strong>Description:</strong></p> 
<p>Amazon EMR is a managed cluster platform that simplifies running big data frameworks on AWS to process and analyze vast amounts of data.</p> 
<p>We identified CVE-2025-8904, an issue in the Amazon EMR Secret Agent component. The Secret Agent component securely stores secrets and distributes secrets to other Amazon EMR components and applications. When using Amazon EMR clusters with one or more Lake Formation, Apache Ranger, runtime role, or Identity Center feature that uses this component, Secret Agent creates a keytab file containing Kerberos credentials. This file is stored in the /tmp/ directory. A user with access to this directory and another account can potentially decrypt the keys and escalate to higher privileges.</p> 
<p>We implemented a fix that removes /tmp/ as a staging directory for Kerberos credentials, eliminating the possibility of users accessing the keytab file. The fix is available in Amazon EMR release 7.5 and higher.</p> 
<p><b>Affected versions:</b></p> 
<p>Amazon EMR version 6.10 through 7.4</p>
